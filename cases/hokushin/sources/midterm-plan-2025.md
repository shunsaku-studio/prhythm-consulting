# 北辰工業 中期経営計画「Hokushin Vision 2025」（FY2023〜FY2025）

> 架空の資料です。

## 1. 目標（2023 年 5 月公表）

| 指標 | FY2022 実績 | FY2025 目標 | 備考 |
|------|------------|------------|------|
| 連結売上高 | 1,710 億円 | 2,300 億円 | M&A による上積み 150 億円を含む（p.6） |
| 営業利益率 | 5.6% | 8.0% | |
| ROE | 6.6% | 8.0% 以上 | |
| 海外売上比率 | 38% | 45% | |
| 配当性向 | 30% | 35% | |

## 2. 重点施策（p.8〜12）

1. EV 向け熱マネジメント部品の拡販（自動車部品）
2. 半導体製造装置向け精密部品の能力増強（産業機械部品）
3. センサー事業の海外展開（電子部品）
4. 成長投資 3 年間で 450 億円（設備 330 億円、M&A 120 億円）

## 3. 最終年度の振り返り（2026 年 5 月 決算説明資料 p.4）

| 指標 | FY2025 目標 | FY2025 実績 | 達成 |
|------|------------|------------|------|
| 連結売上高 | 2,300 億円 | 2,000 億円 | 未達 |
| 営業利益率 | 8.0% | 6.1% | 未達 |
| ROE | 8.0% 以上 | 7.0% | 未達 |
| 海外売上比率 | 45% | 41% | 未達 |

会社の説明（同 p.5）:
- M&A は候補との条件が折り合わず、実行できなかった（上積み 150 億円が未実現）
- 自動車部品は EV 化の遅れで、熱マネジメント部品の立ち上がりが 1 年後ろ倒しになった
- 設備投資は 3 年間で 315 億円を実行（計画 330 億円）

## 4. 次期中計の策定方針（同 p.18）

- 次期中計（FY2026〜FY2030）は 2027 年 5 月に公表予定
- 「長期ビジョン 2035」と合わせて策定する
- 資本コストを上回る ROIC の事業別管理を導入する
