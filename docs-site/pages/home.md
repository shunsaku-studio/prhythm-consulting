# Prhythm for Consulting

**抽象的な依頼を、ジュニアでも組み立てられ、自分の言葉で説明できるビジネスケースへ。**

顧客の抽象的な依頼（「売上を 2,000 億円から 5,000 億円にしたい」など）を、目標・論点・事実・ギャップ・打ち手・資本・KPI の順に一段ずつ具体化する [Agent Skills](https://agentskills.io) 集。

このプロダクトは二つのものでできている。

1. **スキル** — 作業を速く、数字を正確にする。数字はすべて出典タグ付きの台帳に載せ、計算はスクリプトに任せる
2. **[先輩質問タイム](/guide/question-time/)** — スキルで作った成果物を、ジュニアが自分の言葉で説明できるかを先輩が確かめる運用。スキルの外に置く

理解を確かめる仕組みは、スキルの中に置かない。学習用の手順をスキルに仕込んでも、忙しいときに飛ばされるからだ。理解の確認は、人と人の約束としてワークフローの通過条件にする。

```bash
gh skill install shunsaku-studio/prhythm-consulting --all
```
