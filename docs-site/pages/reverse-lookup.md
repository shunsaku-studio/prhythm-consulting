# 依頼の言い方からの逆引き

ジュニアへの依頼は、たいてい動詞で、ざっくりと来る。言われた言葉から、呼ぶスキルを引く。

| 依頼の言い方 | 呼び出すスキル | 作業の型 |
|-------------|---------------|---------|
| 「この会社の数字、10 年分並べといて」 | [company-financials](/skills/company-financials/) | 調べる |
| 「中計、何が書いてあるか整理して」 | [midterm-plan-reader](/skills/midterm-plan-reader/) | 調べる |
| 「社長が何を大事にしてるか見といて」 | [leadership-lens](/skills/leadership-lens/) | 調べる |
| 「5000 億って、年何%？」 | [target-math](/skills/target-math/) | 見積もる |
| 「論点出しといて」 | [issue-tree](/skills/issue-tree/) | 分ける |
| 「2 週間の段取り組んで」 | [workplan](/skills/workplan/) | 分ける |
| 「収益性と効率、同業と比べて見て」 | [financial-analysis](/skills/financial-analysis/) | 読み解く |
| 「この会社、何で伸びてきたの？」 | [growth-decomposition](/skills/growth-decomposition/) | 読み解く |
| 「競合と並べて比べて」 | [competitor-benchmark](/skills/competitor-benchmark/) | 読み解く |
| 「市場規模ざっくり出して」 | [market-sizing](/skills/market-sizing/) | 見積もる |
| 「このままだといくら足りない？」 | [gap-bridge](/skills/gap-bridge/) | 見積もる |
| 「打ち手を洗い出して」 | [option-longlist](/skills/option-longlist/) | 判断材料にする |
| 「その打ち手でいくら稼げる？」 | [initiative-sizing](/skills/initiative-sizing/) | 見積もる |
| 「どれを追うか比べられるようにして」 | [option-evaluation](/skills/option-evaluation/) | 判断材料にする |
| 「それ、お金足りるの？」 | [capital-capacity](/skills/capital-capacity/) | 見積もる |
| 「KPI に分解して」 | [kpi-tree](/skills/kpi-tree/) | 分ける |
| 「事業計画のモデル組んで」 | [business-case-model](/skills/business-case-model/) | 見積もる |
| 「振れ幅見といて」「感応度出して」 | [scenario-sensitivity](/skills/scenario-sensitivity/) | 見積もる |
| 「いつ何で判断するか決めよう」 | [kpi-roadmap](/skills/kpi-roadmap/) | 計画にする |
| 「ストーリーにして」「ゴーストデッキ作って」 | [storyline](/skills/storyline/) | 伝える |
| 「数字の裏取りして」 | [number-audit](/skills/number-audit/) | 点検する |

## このプロダクトで作らないもの

PEST、ファイブフォース、SWOT、3C、バリューチェーン、事例調査、チャート選び、議事録のまとめは、汎用の LLM にそのまま頼めば足りる。スライドの作成は別の道具で行う。ストーリーの見出しと根拠の ID までを [storyline](/skills/storyline/) で用意して渡す。
