# method — 手順と、なぜその順か

## 1. 基準年を再現する

先に FY2025 を開示どおりに再現する。営業利益率、純利益、ROE、投下資本が開示と合わないモデルで 5 年先を語っても、ずれの原因が前提なのか式なのか分からない。`build_model.py` の最初の 3 行（基準年の再現チェック）はそのためにある。

## 2. 入力と計算を分ける

数字は `model/inputs.csv` と `05-initiatives.csv` からだけ入る。xlsx の calc シートは数式だけでできている。

- 率は inputs シートに % の値のまま置き、数式では `inputs!$C$7%` のように後置の % で割合にする。`/100` を直打ちしない
- 数式に残してよい数値は `(1+g)` の 1 だけ
- 施策のない年は空セルにする（0 を打たない）

こうしておくと、仮置きを差し替えたときに `inputs.csv` を直して回し直すだけで済む。number-audit は inputs シートの値と出典タグを台帳と照らし、calc シートの直打ちを拾う。

## 3. 売上から現預金まで、一本の線で積む

売上 → 営業利益 → 減価償却 → 投資 → 運転資本 → NOPAT → FCF → 投下資本 → ROIC → 純利益 → 純資産 → 現預金 の順に積む。借入は一定に置く。こうすると、施策の投資が手元資金を超えた年に現預金がマイナスになり、資金の不足がそのまま見える。借入や増資で埋めた形にしないのは、それを決めるのが資本の段（capital-capacity）と人だからだ。

投下資本、純資産、現預金は次の関係で閉じている。ずれたら式の誤りである。

- 投下資本 ＝ 純資産 ＋ 有利子負債 − 現預金

## 4. 台帳には主要な結果だけを載せる

年 × 項目のすべてを台帳に載せると、台帳が読めなくなる。最終年度の売上（成り行き・施策・連結）、営業利益と利益率、ROIC、ROE、ネット D/E、現預金、FCF と施策投資の累計だけを `F-`（推定）で載せる。ほかの値は `model/model.csv` にあり、xlsx でたどれる。

## 5. 点検してから渡す

1. `check_xlsx.py` で部品、直打ち、数式の再計算を確かめる
2. LibreOffice があれば `--soffice` で、キャッシュ値を消した写しを再計算させる。なければ「表計算ソフトでの再計算は未確認」と書く
3. number-audit で台帳との一致を確かめる

## なぜこの順か

基準年の再現 → 入力の分離 → 積み上げ → 台帳 → 点検 の順にすると、間違いが見つかったときにどこへ戻ればよいかが一つに決まる。逆に、先に Excel を手で組んでから数字を合わせると、どの数字が入力でどれが計算か分からなくなる。
