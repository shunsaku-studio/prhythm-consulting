# questions — 先輩が聞くとよい問い

先輩質問タイムで使う問いの種。スキルの手順からは呼ばない。

| 観点 | 問い | 聞きたいこと |
|------|------|-------------|
| 結論 | このモデルで、FY2030 の売上目標に届く？ 届かないなら、いくら足りない？ | 売上だけでなく、ROIC と現預金も含めて一言で言えるか |
| 出所 | FY2030 の ROIC の数字を、inputs シートの行までたどって説明して。 | ID → inputs → 台帳 → 資料のページ、とたどれるか |
| 前提 | どのドライバーが 1 つ変わると、結論が一番変わる？ それは仮置き？ | 感応度を回す前に、結論を大きく動かす変数の見当が付いているか |
| 弱点 | 現預金がマイナスになる年に、何をして資金を手当てする前提？ | 旗を見落としていないか、モデルの外で決めるべきことを分けているか |
| 別解 | 確度の低い施策を外すと、どの数字がどれだけ変わる？ | ベースケースに何を入れたかの判断を説明できるか |
