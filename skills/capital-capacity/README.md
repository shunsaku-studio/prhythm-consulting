# capital-capacity

## 概要

施策の一覧（05-initiatives.csv）と財務データを渡すと、投資総額と調達余力の対照表が返る。調達余力は、営業 CF（維持投資と配当を引いた後）、最低限を超える手元資金、ネット D/E の上限までの借入余力、資産売却（政策保有株など）に分けて示す。年度ごとのネット D/E と、上限を超える年度も出す。あわせて、施策の増分 ROIC を WACC と比べる。計算は `scripts/capacity.py` が行う。

## 利用メリット

- 売上の打ち手と資金の手当てを、同じ表で突き合わせられる
- 手元資金と借入余力を二重に数えない。ネット D/E では、現金を使うことも借りることも同じだけネット負債を増やすからである
- 期間の合計だけでなく、年度ごとに上限を超えないかが分かる（大型の買収の年に詰まりやすい）
- 増分 ROIC が WACC を下回る施策が分かり、資本効率の目標との矛盾が見える

## 利用シーン

依頼の例: 「それ、お金足りるの？」「投資の手当てできる？」「D/E の上限まで借りたらいくら？」「ROIC 下がらない？」

- お題A: B2B の精密部品メーカー（売上 2,000 億円、自動車部品・産業機械部品・電子部品の 3 事業）の施策の投資を、配当性向 35%、ネット D/E 0.5 倍以内、政策保有株 120 億円の半減の範囲で手当てできるか
- お題B: 自己株買いや成長投資に回せる枠がいくらあるか
- お題C: 新規参入の投資を、既存事業の CF で賄えるか
- お題D: 買収額を、借入余力と資産売却で賄えるか

## 使い方

**いつ使うか:** initiative-sizing で 05-initiatives.csv ができた後。結果を持って、追う打ち手を選ぶゲート（その前に質問タイム②）に進む。

1. 財務方針（配当性向、D/E の上限、WACC、政策保有株の縮減）を開示資料から台帳に登録する
2. 出典のない前提（維持投資、最低手元資金、税率、施策の営業利益率）を仮置きで登録し、差し替え期限を付ける
3. `06-capital-inputs.csv` に key と台帳の ID を書く
4. `python3 skills/capital-capacity/scripts/capacity.py --initiatives 05-initiatives.csv --ledger facts/facts.csv --inputs 06-capital-inputs.csv --financials facts/financials.csv --fy FY2025 --out-md /tmp/06-capital.tables.md --append-ledger --today YYYY-MM-DD`
5. `templates/capital.md` に表を貼り、`06-capital.md` にする
6. 足りないときは、道筋を並べてレビューに出す。どれを選ぶかは人が決める

## 人が決めること

- 最低手元資金を売上の何か月分にするか（仮置きの値を確かめる）
- 足りないときにどの道筋を取るか（打ち手を変える、時期をずらす、目標を見直す）
- D/E の上限や配当性向を変える提案をするか。これは会社の方針で、クライアントが決める。スキルは前提として勝手に変えない

## よく外す点

- 投資を置かずに売上だけを積む
- 手元資金をすべて使える前提にする
- 手元資金と借入余力を足し算で二重に数える
- 期間の合計だけを見て、途中の年度で D/E の上限を超えることを見落とす
- 配当や維持投資を引き忘れる

詳しくは [references/pitfalls.md](references/pitfalls.md)。

## 具体例

| 案 | 投資総額 | 過不足 | ネット D/E の最大 |
|----|---------|-------|----------------|
| 初回案（大型買収あり） | 1,850.0 億円 [C-001] | -657.6 億円 [C-007] | 1.21倍 [C-008] |
| 見直し案 | 1,040.0 億円 [C-012] | 152.4 億円 [C-013] | 0.50倍 [C-014] |

初回案の不足を受けて打ち手に戻った（D-010）。`--label` で案ごとの C- 行を残している。増分 ROIC は 5.8% [C-015] で WACC 6.0% [F-054] を下回る。
