# 評価シナリオ

## お題A（主）: B2B の精密部品メーカー（売上 2,000 億円、自動車部品・産業機械部品・電子部品の 3 事業）

**入力**: 05-initiatives.csv（自前の施策と、海外の同業買収を含む）、financials.csv の FY2025 連結（売上 2,000 億円、営業利益 122.2 億円、純利益 80.7 億円、営業 CF 190 億円、減価償却 90 億円、現金 320 億円、有利子負債 400 億円、純資産 1,150 億円）、資本コストの開示（WACC 6.0% 程度、ネット D/E 0.5 倍以内、政策保有株 簿価 120 億円を FY2028 までに半減）、配当性向 35% の維持（本人発言）。

**期待すること**:
- 開示の方針（配当性向、D/E の上限、WACC、政策保有株）が公開の出典付きで台帳にあり、維持投資・最低手元資金・税率・施策の利益率は仮置きで期限がある
- 営業 CF 余力が、配当と維持投資を引いた後の額になっている
- 手元資金余力と借入余力を足すと、ネット D/E の上限までの枠に一致する（二重に数えていない）
- 年度ごとのネット D/E があり、買収の年に上限を超えるなら示している
- 増分 ROIC と WACC 6.0% を並べている。買収で全社 ROIC が下がるなら書いている
- 足りないとき、道筋（打ち手、時期、目標、財務方針）を並べて止まり、選んでいない
- number-audit がエラーを出さない

**よくない出力の兆候**: 現金 320 億円を全額余力にしている / D/E の上限を勝手に変えている / 期間の合計しか見ていない / 「足りないので買収はやめるべき」と結論している。

## バリエーション D: オーガニック成長では中計に届かない化学メーカー（買収とノンコア整理を検討）

**入力**: 買収候補の想定買収額、売却を検討する事業の簿価と想定売却額、財務方針。

**期待すること**:
- 買収と売却の時期の差で、途中の年度に D/E が上限を超えるかを示している
- 売却する事業の営業 CF が売却後に減ることを、前提と未確認事項に書いている（スクリプトは成り行きの営業 CF を一定で置くため）
- のれんを含む買収額の全体を投下資本に置き、増分 ROIC を出している

## バリエーション B: 現預金と政策保有株が厚い食品メーカー（ROE 5%→8%、PBR 1 倍割れ）

**期待すること**:
- 成長投資と自己株買いに回せる枠を同じ表で示し、どちらに使うかは人が決める論点として残している
- ネット D/E の上限まで借りると ROE は上がるが、上限を変える提案はクライアントの方針の論点として分けている
