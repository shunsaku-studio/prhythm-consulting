# 何を聞いてから始めるか

## ファイルで確かめること

| 確かめること | どこを見るか | ないときの扱い |
|-------------|-------------|---------------|
| 施策の年次の投資 | 05-initiatives.csv | initiative-sizing が先。投資の列が — の施策は、その欄が — のまま出る |
| 基準年度の営業 CF、純利益、売上、現金、有利子負債、純資産、営業利益 | facts/financials.csv | company-financials が先。急ぐなら有報から台帳に直接登録する |
| 配当方針（配当性向） | 決算説明会、統合報告書 | 公開の方針を使う。北辰工業は「配当性向 35% は維持」（本人発言） |
| 財務規律（ネット D/E の上限など） | 資本コストの開示 | 北辰工業は「ネット D/E 0.5 倍以内を目安」（開示 p.4） |
| WACC | 資本コストの開示 | 北辰工業は 6.0% 程度（開示 p.2）。なければ — |
| 資産売却の計画 | 資本コストの開示、中計 | 北辰工業は政策保有株 簿価 120 億円を FY2028 までに半減 |
| 資本効率の目標 | 00-target-spec.md | ROE や ROIC の目標と、増分 ROIC を並べる |

## 仮置きで置くことが多い値

| 値 | 置き方の目安 | 確かめる相手 |
|----|------------|------------|
| 維持投資 | 減価償却費と同額 | インサイドアウトで設備投資の内訳 |
| 最低手元資金 | 売上の 1〜2 か月分 | マネージャー。業種と季節変動で変わる |
| 実効税率 | 30% 前後 | 有報の税効果注記 |
| 施策の営業利益率 | 既存セグメントの利益率か、中計の目標水準 | 先輩。買収先は買収先の実績 |
| 政策保有株の売却額 | 簿価 | 時価と税で変わる。前提と未確認事項に書く |

## 依頼者に聞くこと（1〜2 問まで）

1. 「財務方針（D/E の上限、配当性向）は、今回の検討で動かしてよい前提か、固定か」
2. 「最低限持っておきたい手元資金の目安はあるか」
