# 先輩向けの問いの種

先輩質問タイム②（追う打ち手を選ぶ前）で使う。スキルの手順からは呼ばない。

| 観点 | 問い |
|------|------|
| 結論 | 過不足はいくらで、どの施策を外すと、または時期をずらすと手当てできるか |
| 出所 | 借入余力の計算に使った D/E の上限と自己資本は、どの ID から来ているか。自己資本はいつの値か |
| 前提 | 最低手元資金を 1 か月分から 2 か月分に変えたら、過不足はどう変わるか。施策の CF を入れたらどうか |
| 別解 | ネット D/E がいちばん高くなる年はいつで、その年に何が起きているか。買収を 2 段階に分けたらどうなるか |
| 弱点 | 増分 ROIC が WACC を下回る施策はどれで、それでも追う理由をクライアントにどう説明するか |
