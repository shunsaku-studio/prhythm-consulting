# intake — 何を聞いてから始めるか

## 必ず要るもの

| 項目 | 聞き方 | なぜ要るか |
|------|--------|-----------|
| 社名と証券コード（か EDINET コード） | 「証券コードは分かりますか」 | EDINET の書類一覧から探すため。社名だけだと同名の会社と取り違える |
| 年度の範囲 | 「何年分要りますか。既定は 10 期です」 | 古い年度は EDINET に残っていないことがある |

## あると良いもの

| 項目 | 既定 | 聞き方 |
|------|------|--------|
| 決算期 | 3 月決算を前提にしない | 「決算月はいつですか。決算期の変更はありましたか」 |
| 項目 | method.md の既定の一覧 | 「既定の項目のほかに要るものはありますか（受注残、従業員数など）」 |
| 単位 | 資料の単位のまま。EDINET は百万円に直す | 「億円と百万円、どちらで揃えますか」 |
| EDINET の API キー | なし | 「API キーはありますか。なければ有報の PDF から手で取ります」 |
| 使い道 | — | 「この数字は何に使いますか（成長の内訳、資本の余力、同業比較）」。要る項目が変わる |

## 聞かないこと

- 社内の管理会計の数字（アウトサイドインでは使わない。受注後に `client/` へ）
- 「どの年が異常だと思うか」。不連続はスクリプトと注記で見つける

## 開始の宣言

```text
対象: 北辰工業（証券コード —）
年度: FY2016〜FY2025（10 期）
入手先: 有報の抜粋 CSV（sources/yuho-excerpt.csv）。EDINET の API キーなし
単位: 億円（資料のまま）
```
