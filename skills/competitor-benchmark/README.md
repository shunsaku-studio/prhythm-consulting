# competitor-benchmark

## 概要

対象企業の財務（financials.csv）と、競合の公開財務（縦持ちの CSV）を渡すと、財務・KPI・戦略を並べた比較表を返す。財務は売上、営業利益、営業利益率、当期純利益、ROE、売上の年平均成長率。戦略・KPI は海外売上比率、M&A 投資額累計、主力セグメント。定義の違う数字（IFRS の事業利益と日本基準の営業利益、売上収益と売上高、違う期の値など）は、注記なしで同じ列に置かない。

## 利用メリット

- 定義の違いが注記（※）で必ず見えるので、きれいだが中身の混ざった表を作らずに済む。
- 年平均成長率を全社に共通する期間でそろえ、その期間を列名に書く。
- 「競合は何で伸びたか」（オーガニックか M&A か、どの事業か、どの地域か）が 1 枚で読める。
- すべての数字が ID 付きで台帳に載るので、後の分析やストーリーがそこから引ける。

## 利用シーン

- 現状分析（お題A の 1 週目）で、自社の立ち位置と競合の伸び方を見たいとき
- ROE や利益率が同業と比べてどうかを問われたとき（お題B）
- 新しい市場の既存プレイヤーを並べたいとき（お題C）、買い手と売り手を比べたいとき（お題D）

依頼の例: 「競合と比べて」「同業比較の表作って」「うちの ROE って同業と比べて低い？」「大和テクノはなんで伸びてるの？」

## 使い方

**いつ使うか:** company-financials で financials.csv ができた後に入る。growth-decomposition と並行して進めてよい。結果は financial-analysis、gap-bridge、option-longlist、storyline の材料になる。

1. 比べる競合（3〜5 社）と、それぞれを選んだ理由を決める。
2. 競合の数字を、資料にある科目名と会計基準のまま縦持ちの CSV に集める。対象企業の海外売上比率など、financials.csv にない数字は追加の CSV に入れる。
3. スキルが `scripts/benchmark.py` を回す。定義の違いには ※ の注記が付く。説明できない違いは — にして「置かなかった値」に出る。
4. スキルが `facts/competitor-benchmark.md` を書き、競合の数字と比率を台帳に足す。
5. スキルが、競合ごとに「何で伸びたか」を 2〜4 行で書く。

## 人が決めること

- 比べる競合と、選んだ理由
- IFRS の会社で、営業利益の列にどの利益を置くか（事業利益か営業利益か）
- 説明できない定義の違いを、— で残すか、別の科目で比べるか

単独度は ◎（ひとりで完結）。上の 3 点に迷ったときだけ止まって聞く。

## よく外す点

- 定義の違う数字を同じ列に並べる（IFRS の事業利益と日本基準の営業利益など）
- FY2021→FY2025 の 4 年の伸びを「5 年 CAGR」と呼ぶ
- 対象企業の「子会社株式の取得による支出」と、競合の「M&A 投資額」を同じものとして比べる
- 比率を並べるだけで、競合が何で伸びたかに踏み込まない

詳しくは [references/pitfalls.md](references/pitfalls.md)。
