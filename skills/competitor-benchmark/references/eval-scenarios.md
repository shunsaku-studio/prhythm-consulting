# 評価シナリオ（competitor-benchmark）

スキルの出来を確かめるためのお題。採点は [eval-rubric.md](eval-rubric.md) で行う。

## シナリオ1（主）: お題A B2B の精密部品メーカー（売上 2,000 億円、自動車部品・産業機械部品・電子部品の 3 事業）と競合 3 社

### 渡すもの

- `case/sources/competitors.csv`（競合 A: 自動車部品中心、日本基準。競合 B: 電子部品中心、IFRS。競合 C: 買収で拡大）
- `case/facts/financials.csv`（company-financials の出力。この会社 FY2016〜FY2025、セグメント別）
- この会社の海外売上比率（中計の振り返り。台帳の ID 付き）
- 依頼: 「競合と比べて。5,000 億円に向けて、競合が何で伸びたかを知りたい」

### 期待する振る舞い

| 点検 | 期待 |
|---|---|
| IFRS の利益 | 競合 B の事業利益 176 億円に ※ を付け、日本基準の営業利益と定義が違うと書く。IFRS の営業利益 150 億円（減損 26 億円を含む）も注記に出す |
| 売上の定義 | 競合 B の売上収益に ※ を付ける |
| ROE の分母 | 競合 B は親会社の所有者に帰属する持分、他社は純資産。違いを ※ で示し、期末の値で割ったと書く |
| 期間 | 競合の売上は FY2021 と FY2025 しかない。年平均成長率を FY2021→FY2025（4 年）で全社そろえ、「5 年」と呼ばない |
| M&A | この会社は FY2021〜FY2025 の子会社株式の取得による支出の合計 0 億円を、定義の違う値として ※ 付きで置く。FY2019 の小規模な精密部品会社の買収（期間外）を注記に出す |
| 主力セグメント | この会社は自動車部品の構成比をセグメント売上から計算する。競合 C は 2 セグメントを並べる |
| 読み | 競合 C の伸びの多くが FY2022 の米国同業の買収によると書く。競合 A はオーガニック中心と書く |
| 台帳 | 表のすべての数字に ID。競合の数字は公開、比率は推定（計算式に入力 ID）。number-audit でエラー 0 件 |
| 止まる場所 | 定義の違いを — にするか別の科目で比べるかに迷ったときだけ聞く。競合の選び方を勝手に増やさない |

## シナリオ2（変化球）: お題B 現預金と政策保有株が厚い食品メーカー（売上 3,000 億円、ROE 5%、PBR 1 倍割れ）の資本効率

### 渡すもの

- 現預金と政策保有株が厚い食品メーカー（売上 3,000 億円、ROE 5%、PBR 1 倍割れ、日本基準）の financials.csv
- 同業 3 社。うち 1 社は IFRS で「親会社の所有者に帰属する持分」と「事業利益」を開示、1 社は 12 月決算
- 依頼: 「ROE が同業と比べてどれくらい低いか、何が効いていないかを見たい」

### 期待する振る舞い

- ROE の分母（純資産と親会社の所有者に帰属する持分）の違いを ※ で示す
- 12 月決算の会社について、決算月が違うことを書く（FY の表記だけでそろったと見なさない）
- 営業利益率の差を、事業構成の差と定義の差に分けて書く
- 比率の順位で終わらせず、利益率・回転率・レバレッジのどこが効いていないかを financial-analysis に渡す材料として書く

## シナリオ3（変化球）: 定義の説明がない値

### 渡すもの

- シナリオ1 の入力に、米国基準の会社を 1 社足す（売上高と営業利益。FY2024 まで）
- 依頼: 「海外の同業も 1 社入れて比べて」

### 期待する振る舞い

- 米国基準の値は、説明を用意していないので列に置かない（—）。スクリプトは終了コード 1 を返す
- 「置かなかった値」を示し、資料で定義を確かめて注記を足すか、— のまま残すかを人に聞く
- CSV の basis を「日本基準」に書き換えて通すことはしない
- 仮に定義を確かめて置く場合も、FY2024 の値であることを ※ で示す
