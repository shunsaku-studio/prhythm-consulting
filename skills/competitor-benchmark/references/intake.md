# 何を聞いてから始めるか（competitor-benchmark）

分かっていることは聞かない。分からない値は — のまま進め、「前提と未確認事項」に書く。

## 1. 比べる目的

論点ツリーのどの問いに答えるための比較かを確かめる。目的で、並べる列と競合が変わる。

| 目的の例 | 重い列 |
|---|---|
| 何で伸びたか（お題A） | 売上の年平均成長率、M&A 投資額、主力セグメント、海外売上比率 |
| 資本効率はどうか（お題B） | ROE、営業利益率、純資産、総資産 |
| 誰がどこに立っているか（お題C） | 主力セグメント、海外売上比率、売上規模 |
| 買い手と売り手（お題D） | M&A 投資額、売上規模、利益率 |

## 2. 比べる競合

- 3〜5 社。多すぎると読みが薄くなる
- 社ごとに、選んだ理由を一言で書く（同じ顧客、同じ製品、目標とする規模、M&A で伸びた例 など）
- 規模だけで選ばない。事業の構成が大きく違う会社は、理由を書いたうえで入れる

## 3. 対象企業の数字

- `facts/financials.csv`（company-financials の出力）があるか。なければ先に company-financials を回す
- financials.csv にない戦略・KPI（海外売上比率など）は、どの資料のどこにあるか。台帳の ID があるか

## 4. 競合の数字

競合の数字は、資料にある科目名と会計基準のまま集める。

| 列 | 書くこと |
|---|---|
| company | 会社名 |
| fiscal_year | `FY2025`。累計は `FY2021-FY2025` |
| item | 資料の科目名のまま（売上収益、事業利益、親会社の所有者に帰属する持分 など） |
| value / unit | 数値と単位（億円 / 百万円 / %） |
| basis | 日本基準 / IFRS / 米国基準 |
| source | 資料名（とページ） |
| note | 資料にある注意書き（減損を含む、独自の段階利益 など） |
| id | 台帳に既にある値なら、その ID |

## 5. 比較年と期間

- 比較年: 既定は全社の最新年のうち最も早い年。決算月が違う会社がないか
- 年平均成長率の年数: 既定 5 年。全社でそろわなければ、短い期間にそろえて列名に書く

## 6. 決めておくこと

- IFRS の会社の営業利益の列に、事業利益と営業利益のどちらを置くか（既定は事業利益。もう一方は注記に出る）
- 決めたら decisions.md に D-xxx で残す
