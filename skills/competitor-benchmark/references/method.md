# 手順と、なぜその順か（competitor-benchmark）

## 1. 目的と競合を先に決める

比べる目的が決まらないと、列が増え続ける。論点ツリーの問いを 1 つ選び、その問いに答える列だけを並べる。競合は 3〜5 社にとどめ、選んだ理由を書く。

## 2. 資料の科目名のまま集める

競合の数字を集めるとき、科目名を自分で読み替えない。IFRS の「売上収益」を「売上高」と書き換えると、後で定義の違いに気づけなくなる。読み替えは、スクリプトが注記付きで行う。

資料にある注意書き（「減損 26 億円を含む」「事業利益は売上総利益 − 販管費」）は note に写す。注記の材料になる。

## 3. スクリプトで表にする

`scripts/benchmark.py` が次を行う。

| 処理 | 中身 |
|---|---|
| 列の基準 | 日本基準の科目（売上高、営業利益、親会社株主に帰属する当期純利益、純資産、総資産）を基準にする |
| 注記 | 基準と違う科目には、違いを説明した ※ を付ける。説明のない組み合わせは置かない（—） |
| 期のずれ | 比較年の値がない会社は、最も近い過去の期を ※ 付きで置く |
| 年平均成長率 | 全社に共通する期間でそろえ、期間と年数を列名に書く |
| 比率 | 営業利益率 = 営業利益 / 売上、ROE = 当期純利益 / 期末の純資産 |
| 対象企業の M&A | 競合の M&A 投資額累計と同じ期間の「子会社株式の取得による支出」を足す。定義が違うことを ※ で示す。期間外の買収は注記に出す |
| 主力セグメント | 競合は資料の記載から、対象企業はセグメント売上の構成比から |
| 台帳 | 競合の数字は公開、比率は推定（計算式に入力 ID）で台帳に足す |

なぜスクリプトか: 比率は会話の中で計算すると、丸めや取り違えが混ざる。スクリプトなら計算式が台帳に残り、number-audit で点検できる。

## 4. 注記と「置かなかった値」を読む

表より先に注記を読む。注記の数が多い会社は、そもそも比べ方を考え直す。

「置かなかった値」が出たら、次のどちらかにする。

1. 資料で定義の違いを確かめ、説明を `scripts/benchmark.py` の `NOTES` に足す（出典を書く）
2. — のまま残し、「前提と未確認事項」に書く

科目名を書き換えて列に押し込むことはしない。

## 5. 読みを書く

表の下に、競合ごとに 2〜4 行で「何で伸びたか」を書く。数字には ID を付ける。

- 伸び方: オーガニックか M&A か。M&A なら、いくらで何を買い、売上がいくら乗ったか
- どこで: 主力セグメント、海外売上比率
- 利益: 営業利益率の差は、事業構成の差か、定義の差か

例（形だけ）:

> 大和テクノHD は FY2021→FY2025 に年 9.9% [F-xxx] で伸びた。うち FY2022 の米国同業の買収（800 億円、売上寄与 年 900 億円）が大きい。M&A 投資額累計 1,100 億円 [F-xxx]。オーガニックの伸びは、買収の寄与を除くと —（growth-decomposition で確かめる）。

比率の順位を書くだけで終わらせない。順位は表を見れば分かる。

## 6. 渡す

`facts/competitor-benchmark.md` を書いたら、次の段（financial-analysis、gap-bridge、option-longlist）に渡す。競合の伸び方は、二本目のレーン（M&A、市場の選び直し）の材料になる。
