# financial-analysis

## 概要

company-financials が作った `facts/financials.csv` を渡すと、収益性・効率性・安全性の比率を年度ごとに出し、ROE を純利益率 × 総資産回転率 × 財務レバレッジに分け、ROIC を定義付きで出す。2 時点の間の変化は、ROE のどの要因が効いたか、営業利益率のうちセグメントの構成と利益率のどちらが効いたかに分ける。そのうえで、変化の要因を仮説として書き、確かめる資料を添える。成果物は `facts/financial-analysis.md` と台帳の行である。

## 利用メリット

- 比率の計算をスクリプトで行い、すべての比率に計算式と入力の ID が残る。
- ROE と営業利益率の変化を要因に分けるので、「上がった」で終わらず「何が効いたか」まで言える。
- ROIC の定義を CONVENTIONS の共通の定義（純資産 + 有利子負債 − 現金及び預金）にそろえるので、capital-capacity や business-case-model の ROIC と同じ物差しで並べられる。税率は仮置きとして明示する。
- 同業比較で、会計基準や利益の定義の違いを表の中に書く。

## 利用シーン

- 対象企業の財務の体力と稼ぐ力を、提案の前に押さえたいとき
- ROE 目標の達成の道筋を考える前に、今の ROE が何で決まっているかを見たいとき
- 資本の余力（capital-capacity）を見る前に、ネット有利子負債と FCF を揃えたいとき

依頼の例: 「この会社の財務、ざっと見て」「ROE を分解して」「利益率が上がった理由は？」

## 使い方

**いつ使うか:** company-financials の後に使う。お題A では 3 段目（現状と成長の内訳）、お題B では最初の分析になる。出力は capital-capacity、growth-decomposition、gap-bridge が読む。

1. `facts/financials.csv` と、比べる 2 時点を渡す。組み替えをまたがない期間を選ぶ（`facts/financials.md` の不連続の一覧を見る）。
2. スキルが `ratios.py` で比率、DuPont 分解、ROIC、要因分解、同業比較を出す。
3. スキルが、動いた要因ごとに理由の仮説と、確かめる資料を書く。確かめられたものだけ「確認済み」とする。
4. 税率の仮置きを、有報の法定実効税率に差し替える。余剰現金だけを引く定義を使ったときは、その月数も差し替える。

## 人が決めること

このスキルには止まって決めてもらう場面はない（単独度 ◎）。次は人が確かめる。

- 要因の仮説が正しいか。有報の MD&A や説明会資料で裏を取るのは人の仕事である。
- ROIC の定義を共通の定義から変えるか（余剰現金だけを引く、株主資本を使う など）。変えたら、その旨を前提に書き、他のスキルの ROIC と並べない。

## よく外す点

- 比率を並べるだけで、要因に踏み込まない。
- 組み替えや買収をまたいだ期間で、セグメントの構成の効果を読む。
- ROIC の税率や投下資本の定義を書かない。
- 定義の違う同業の数字（IFRS の事業利益と日本基準の営業利益）を同じ列で比べる。

詳しくは [references/pitfalls.md](references/pitfalls.md)。

## 具体例

FY2021 → FY2025 の ROE の変化のうち、純利益率の寄与は 0.89pt [F-282]、総資産回転率は 0.37pt [F-283]、財務レバレッジは -0.08pt [F-284]。営業利益率の変化では、自動車部品の利益率の効果 0.53pt [F-296] が最も大きい。ROIC は 7.1% [F-276]（投下資本 = 純資産 + 有利子負債 − 現金及び預金、税率 30.0% [F-248] は仮置き）で、WACC 6.0% [F-054] をわずかに上回る。全体は [cases/hokushin/facts/financial-analysis.md](../../cases/hokushin/facts/financial-analysis.md)。

## 先輩が聞くとよい問い

[references/questions.md](references/questions.md) に問いの種を置いている。スキルの手順からは呼ばない。

- ROE が上がった一番の理由は何か。それはどの資料で確かめたか。
- 税率を 30% から実効税率に変えたら、ROIC と WACC の差はどう動くか。
