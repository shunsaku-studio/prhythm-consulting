# intake — 何を聞いてから始めるか

## 必ず要るもの

| 項目 | 聞き方 | なければ |
|------|--------|---------|
| `facts/financials.csv` | 「company-financials の出力はありますか」 | 先に company-financials を回す |
| 分析の目的 | 「何を見るための分析ですか（成長の余力、ROE の道筋、資本の余力）」 | 既定の比率を全部出し、要因分解は ROE と営業利益率で行う |

## あると良いもの

| 項目 | 既定 | 聞き方 |
|------|------|--------|
| 比べる 2 時点 | 最初と最後の年 | 「どの 2 時点を比べますか。組み替えのある年（`facts/financials.md` 参照）をまたがない期間を勧めます」 |
| 税率 | 30%（仮置き） | 「有報の税効果会計の注記に法定実効税率はありますか」 |
| 事業に要る現金 | 月商 1 か月（仮置き） | 「業界で手元に置く現金の目安はありますか」 |
| 残高の取り方 | 期首と期末の平均 | 「会社の開示する ROE は期末ですか、期中平均ですか」 |
| 会社自身の目標と規律 | — | 「資本コストの開示（株主資本コスト、WACC、ネット D/E の上限）はありますか」 |
| 同業のデータ | なし | 「比べたい同業はどこですか。データは competitors.csv の形でありますか」 |

## 聞かないこと

- 「この会社は良い会社ですか」。良し悪しの判断はしない。比率と要因を示す
- 株価や目標株価（対象外）

## 開始の宣言

```text
入力: facts/financials.csv（FY2016〜FY2025、日本基準）
比べる 2 時点: FY2021 → FY2025（FY2021 のセグメント組み替えの後）
仮置き: 税率 30%、事業に要る現金は月商 1 か月
残高: 期首と期末の平均。会社開示の ROE（期末）とは少しずれる
同業: 競合 A、競合 B（IFRS）、競合 C
```
