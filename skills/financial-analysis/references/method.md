# method — 手順と、なぜその順か

## 全体の順番

1. 入力の不連続を確かめる
2. 比率を出す（水準）
3. 変化を要因に分ける
4. 要因の理由を仮説にし、確かめる資料を添える
5. 同業と比べる
6. 後のスキルに渡す

比率を出すのは手段で、目的は「何が効いて今の数字になっているか」を言えるようにすることである。だから 3 と 4 を省いた出力は、このスキルの出力として扱わない。同業比較を最後に置くのは、自社の要因が分かっていないと、同業との差の理由も読めないからである。

## 1. 入力の不連続

- `facts/financials.md` の不連続の一覧を読む
- 比べる期間がセグメントの組み替えをまたぐと、構成の効果に区分の移動が混ざる。組み替えの後の年を起点にする
- 買収の年をまたぐなら、回転率とレバレッジの変化に買収（のれん、借入）が入る

## 2. 水準

| 区分 | 比率 | 定義 |
|------|------|------|
| 収益性 | 営業利益率、純利益率 | 売上に対する比 |
| | ROE | 純利益 ÷ 純資産（期中平均） |
| | ROA | 純利益 ÷ 総資産（期中平均） |
| | ROIC | NOPAT ÷ 投下資本（期中平均）。下の定義 |
| 効率性 | 総資産回転率 | 売上 ÷ 総資産（期中平均） |
| 安全性 | 自己資本比率 | 純資産 ÷ 総資産（期末） |
| | ネット有利子負債、ネット D/E | 有利子負債 − 現金及び預金、それ ÷ 純資産 |
| CF | フリー CF | 営業 CF − 設備投資額（M&A は別に見る） |
| | 設備投資 ÷ 減価償却 | 1 倍を下回ると、能力の維持に足りていない可能性 |
| | 配当性向 | 配当金の支払額 ÷ 純利益（CF ベースの近似） |

ROIC の定義:

- NOPAT = 営業利益 × (1 − 税率)。税率は仮置き 30%。有報の法定実効税率で差し替える
- 投下資本 = 純資産 + 有利子負債 − 現金及び預金（CONVENTIONS の共通の定義。capital-capacity と business-case-model も同じ定義を使う）
- 余剰現金だけを引く定義にしたいときは `--cash-months` を渡す。余剰現金 = max(0, 現金及び預金 − 売上 × 月数 ÷ 12)。月数は仮置き。この定義を使ったら、前提に「必要現金を月商 x か月と置いた」と書く

会社自身の目標や規律と並べる。お題A なら、株主資本コスト 7.5%、WACC 6.0%、ネット D/E 0.5 倍以内（資本コストの開示 p.2、p.4）。並べる値には台帳の ID を付ける。

## 3. 変化を要因に分ける

ROE の分解:

- ROE = 純利益率 × 総資産回転率 × 財務レバレッジ。同じ残高（期中平均）を使うと、掛け算が ROE に一致する
- 2 時点の変化は、各要因の対数の変化の比で按分する。足すと ROE の変化（pt）に一致する

営業利益率の分解:

- 連結の営業利益率 = Σ（セグメントの売上構成比 × セグメント利益率）+ 調整額 ÷ 売上
- 構成の効果 = Σ（構成比の変化 × 前の利益率）
- 利益率の効果 = Σ（後の構成比 × 利益率の変化）
- 残り = 調整額（全社費用）と端数

## 4. 要因の理由

分解は「どこが動いたか」までしか言わない。「なぜ動いたか」は資料で確かめる。

| 動いたもの | 考えられる理由の型 | 確かめる資料 |
|----------|----------------|------------|
| セグメント利益率 | 価格、数量（稼働率）、原材料、為替、固定費、一過性の損益 | 有報の MD&A（経営成績の分析）、決算説明会資料の増減益要因 |
| 構成比 | セグメントの伸びの差、組み替え、買収 | セグメント情報、企業結合の注記 |
| 総資産回転率 | 売上の伸び、在庫・売掛の増減、設備の増加 | BS の内訳、CF 計算書 |
| 財務レバレッジ | 借入、自社株買い、利益の積み上がり | 財務 CF、株主資本等変動計算書 |

書き方:

- 「確認済み」は資料名とページを付ける
- 確かめていないものは「未確認」とし、確かめる資料を書く。推測を事実の形で書かない

## 5. 同業と比べる

- 会計基準と利益の定義を先に確かめる。IFRS の「事業利益」は会社ごとの定義。IFRS の持分は非支配持分を含まない
- 違いは表の「定義の注意」列に書く。違うものは同じ列で比べられないと書く
- 詳しい比較（KPI、戦略）は competitor-benchmark に任せる

## 6. 渡す

- capital-capacity: ネット有利子負債、ネット D/E、フリー CF、ROIC
- growth-decomposition、gap-bridge: セグメント利益率と構成比
- business-case-model: ROIC の定義（同じ定義を使う）
