# five-forces

## 概要

答えたい問い（参入するか、どのセグメントに寄るか、買収先の業界は魅力的か）と業界の範囲を渡すと、ファイブフォースの表を返す。表には、5 つの力ごとの要因と証拠、強さ（強・中・弱）と理由、これからの向きが入る。成長率・技術・規制・補完財は「力ではない要因」として別表に置き、どの力を通じて効くかを書く。最後に、業界の構造の読みを同業の利益率・ROIC の実績と突き合わせる。

## このフレームワークについて

Michael Porter が 1979 年に Harvard Business Review で示し、2008 年に同誌で改めて整理した。業界の利益は、新規参入の脅威、売り手の交渉力、買い手の交渉力、代替品の脅威、既存企業どうしの競争の 5 つの力で決まる、という考え方である。答えるのは「この業界はなぜこの程度しか（またはこれほど）儲かるのか」と「その中のどこに立てば利益を守れるか」の 2 つ。自社の強み・弱みの棚卸しではない。市場の成長の予測でもない。成長率の高い業界が儲かる業界とは限らない、というのがこの道具の要点の一つである。

## 利用メリット

- 業界の範囲を最初に決めるので、「何の業界の話か分からない表」にならない
- 要因ごとに証拠か — が付くので、強さの判断を後からたどれる
- 成長率や技術を力と混ぜないので、「伸びる市場 = おいしい市場」という早合点を防げる
- 構造の読みを利益の実績で確かめるので、もっともらしい話で終わらない

## 利用シーン

- お題C（新規参入）: 参入を考える業界の儲かりやすさを見たいとき。参入方式を考える前
- お題A（売上成長）: 2 つの事業の業界を比べ、投資の重心をどちらに寄せるか考えたいとき
- お題D（M&A）: 買収先の業界が構造的に魅力的かを見たいとき

依頼の例: 「ファイブフォースやって」「業界の儲かりやすさ見て」「この業界、参入して儲かる？」「自動車向けと半導体向け、どっちの業界がおいしい？」

## 使い方

**いつ使うか:** 論点ツリー（issue-tree）で問いが決まった後。同業の利益率は [competitor-benchmark](../competitor-benchmark/README.md)、市場の大きさは [market-sizing](../market-sizing/README.md) の結果を使う。結果は [option-longlist](../option-longlist/README.md) と [option-evaluation](../option-evaluation/README.md) の材料になる。お題D では、候補探し（ma-screening、Phase 2 で作る予定）の材料にもなる。

1. 答える問いと使い道を決める。
2. スキルが業界の定義の案（製品の範囲、地理の範囲、参加者）を出す。力の違う範囲は別の業界に分ける。ここで止まり、人が定義を決める。
3. スキルが力ごとに要因を挙げ、証拠（台帳の ID か資料のページ）を付ける。分からない要因は — にする。
4. スキルが強さ・理由・向きを付け、力ではない要因を別表に置く。
5. スキルが同業の利益率・ROIC の実績と突き合わせ、全体の構造の案と位置どりの論点を書く。ここで止まり、人が総合判断を決める。
6. スキルが `frameworks/five-forces.md` を書き、number-audit で数字を点検する。

## 人が決めること

- 業界の定義（製品の範囲、地理の範囲、分けるかどうか）。decisions.md に D-xxx で残す
- 総合判断（業界、またはどのセグメントが構造的に魅力的か）。decisions.md に D-xxx で残す
- 参入するか、どちらに寄るか、買うかは、この表では決めない

単独度は ○（結果をレビューに出す前提）。上の 2 か所で止まって聞く。

## よく外す点

- 業界の範囲を決めずに枠を埋め始める
- 成長率・技術・規制・補完財を、6 本目の力として数える
- 「買い手の力: 強」とだけ書き、何を見たかを書かない
- 業界の構造と、自社の強みを混ぜる
- 構造の読みを、利益の実績と突き合わせない

詳しくは [references/pitfalls.md](references/pitfalls.md)。

## 具体例

B2B の精密部品メーカー（売上 2,000 億円、自動車・産業機械・電子の 3 事業）が、投資の重心を自動車向けと半導体製造装置向けのどちらに寄せるかを考える場面。抜粋で、ID は説明用である。

| 力 | 自動車向け精密部品（世界） | 半導体製造装置向け精密部品（世界） |
|---|---|---|
| 新規参入 | 中・強まる（EV 部品で電機系が入る余地。推測） | 弱〜中・横ばい（精度と設計段階からの技術営業が要る） |
| 買い手 | 強・横ばい（自動車メーカーは少数で値下げ要求が強い。顧客集中度は —） | 中・横ばい（精度が装置の性能を左右し、切り替えにくい。推測） |
| 代替品 | 強・強まる（内燃機関向けは年 −2% [F-xxx]） | 弱（公開情報では見当たらない） |

| 力ではない要因 | 通じて効く力 |
|---|---|
| 成長率（半導体装置向けは年 9% [F-xxx]） | 新規参入と競争（投資の波で不況期に値下げが起きる） |
| 技術（電動化） | 自動車向けの代替品と新規参入 |

自社のセグメント利益率は産業機械部品が自動車部品を上回り、構造の読みと向きは合う。ただし半導体装置向けの数字は産業機械向け全体で代用しており、証拠は弱い。総合判断は人の確認待ち。
