# 評価シナリオ（five-forces）

スキルの出来を確かめるためのお題。会社と数値は説明用の仮のものである。採点は [eval-rubric.md](eval-rubric.md) で行う。

## シナリオ1（主）: お題C 工場向けエネルギー管理サービスへの参入

### 渡すもの

- 依頼主: 既存事業が成熟した産業機器メーカー（国内中心）
- 依頼: 「工場向けのエネルギー管理サービスに出るべきか。この業界、参入して儲かる？」
- 公開情報の束: 業界団体の市場見通し（国内、年成長率の見通し付き）、同業 3 社の有報（計測機器メーカー、電力会社系のサービス会社、ソフトウェア会社）、省エネ関連の補助制度の概要
- 台帳: 同業の営業利益率が 1 年分だけ載っている。ROIC はない

### 期待する振る舞い

| 点検 | 期待 |
|---|---|
| 問い | 「参入するか」の判断材料であると冒頭に書く。結論（出る・出ない）は書かない |
| 業界の定義 | 製品の範囲を決めずに始めない。「サービス（監視・分析・運用代行）」と「ハード（計測機器、制御機器）」を含めるかを分けて示す。地理は国内か、据え付けと保守の届く地域かを書く。定義の案を出したところで止まる（ゲート1） |
| 参加者 | 競合に、隣の業界からの参入候補（電力会社、ソフトウェア会社、機器メーカー）を挙げる |
| 新規参入 | 依頼主にとっての参入障壁（顧客の工場への据え付け実績、データの蓄積）と、業界全体の参入障壁を分けて書く |
| 代替品 | 工場が自前で行うエネルギー管理（社内の設備担当）、省エネ設備への置き換えを代替品として挙げる |
| 力ではない要因 | 補助制度は規制・政策として別表に置き、「新規参入（障壁を下げる）と買い手（補助の対象が価格への敏感さを変える）」を通じて影響すると書く。成長率の高さを魅力度に直結させない |
| 利益の実績 | 同業の営業利益率が 1 年分しかないことを書き、総合判断の証拠が弱いと明記する。足りない年は competitor-benchmark に返す |
| 証拠 | 顧客の集中度など資料にない要因は — か 推測 にする。もっともらしい数字で埋めない |
| 止まる場所 | ゲート1（業界の定義）とゲート2（総合判断）で止まり、D-xxx に残すよう求める |

## シナリオ2（変化球）: お題A セグメント比較

### 渡すもの

- 依頼主: B2B の精密部品メーカー（売上 2,000 億円、自動車・産業機械・電子の 3 事業）
- 依頼: 「自動車向けと半導体製造装置向け、どっちの業界がおいしい？ 投資の重心をどちらに寄せるか考えたい」
- 台帳: 工業会の世界市場（自動車向け、産業機械向け）と成長の見通し。自動車向けの中では内燃機関向けが減り、EV 熱マネジメント向けが伸びる。半導体製造装置向けの市場規模は産業機械向けの内訳としてしかない。自社のセグメント利益率（複数年）。同業の営業利益率（自動車中心の 1 社、両方にまたがる 1 社）

### 期待する振る舞い

- 2 つの業界を同じ型で並べる
- 自動車向けの中で代替品の向きが逆（内燃機関向けは強まる、EV 向けは追い風）であることに気づき、分けるか、分けない理由と差を書く
- 半導体製造装置向けの数字を産業機械向け全体で代用したところに、代用と書く
- 「半導体向けは成長が高いので魅力的」と書かない。成長を参入と競争（投資の波による値下げ）を通じて書く
- 両方の事業にまたがる同業の利益率を、どちらかの業界の証拠として使わない
- 自社のセグメント利益率を、構造の読みと向きが合うかの点検に使う。ただし業界の平均ではないと書く
- どちらに寄せるかは書かず、位置どりの論点として返す

## シナリオ3（変化球）: 問いのない依頼

### 渡すもの

- 依頼: 「とりあえずファイブフォースやっといて」（業界も問いも指定なし。依頼主は化学メーカー）

### 期待する振る舞い

- 枠を埋め始めない。何に答えるための分析か（参入、セグメントの選択、買収先の業界の魅力）と、業界の範囲を聞く
- 聞けない場合は、問いと定義の案を 2〜3 個示して止まる
