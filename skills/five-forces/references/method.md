# 手順と、なぜその順か（five-forces）

ファイブフォースは、業界の利益がなぜその水準なのかを説明する道具である。強さを並べることが目的ではない。手順は Porter（2008）が示した業界分析の進め方に沿う（出典は [sources.md](sources.md)）。

## 1. 問いを決める

問いで、どの業界をどこまで細かく見るかが決まる。問いなしに始めると、範囲が広がり続ける。

## 2. 業界を定義する（ゲート1）

製品の範囲と地理の範囲を決め、参加者を並べ、必要ならセグメントに分ける。

なぜ最初か: 範囲を間違えると、すべての力の評価が間違う。範囲が広すぎると違う構造の業界が混ざり、平均の評価になる。狭すぎると代替品や参入候補を見落とす。Porter はこれを最も多い誤りの一つとしている。

分けるかどうかの基準: 力のどれかが違うなら分ける。例: 自動車向けの中でも、内燃機関向けと EV 向けでは代替品の向きが逆なので、本来は別の業界である。

ここで止まり、人に定義を決めてもらう。

## 3. 力ごとに要因を見る

各力について、下のチェックリストから要因を拾い、証拠を付ける。証拠がなければ — にする。

### 新規参入の脅威（参入障壁の高さで決まる）

| 要因 | 見ること |
|---|---|
| 規模の経済（供給側） | 最小の効率的な規模が市場に比べて大きいか |
| ネットワーク効果（需要側） | 利用者が多い会社ほど選ばれるか |
| 買い手の切り替えコスト | 認証、設計の作り込み、教育の手間 |
| 必要な資本 | 設備、研究開発、立ち上げの赤字 |
| 規模と無関係な既存企業の優位 | 技術、立地、経験、ブランド |
| 流通・販路への入りにくさ | 既存の代理店、系列 |
| 政府の政策 | 許認可、規格、補助 |
| 既存企業の報復の見込み | 過去に値下げで新規参入を退けたか |

### 売り手の交渉力

売り手の集中度、業界が売り手にとって大事な顧客か、切り替えコスト、投入物の差別化、代わりがあるか、売り手が川下に進む恐れ。

### 買い手の交渉力

買い手の数と規模、製品の標準化、切り替えコスト、買い手が川上に進む恐れ。価格への敏感さ（買い手のコストに占める割合、買い手の利益の厚さ、品質への影響）。

### 代替品の脅威

同じ用途を別のやり方で満たすものの価格と性能、買い手の切り替えコスト。業界の外にあるので見落としやすい。

### 既存企業どうしの競争

競合の数と規模の近さ、業界の成長の遅さ、撤退障壁、競合の目標の違い（市場シェアに強くこだわる会社がいるか）。そして競争の形: 価格で争うか（利益を直接削る）、性能・サービス・ブランドで争うか（利益を削りにくい）。固定費が高い、在庫が腐る、生産能力を大きな単位でしか足せない業界は、値下げが起きやすい。

## 4. 強さと向きを付ける

- 強さは「業界の利益をどれだけ押し下げるか」。対象企業の強み・弱みではない
- 理由を要因から 1〜2 個書く。要因の多くが — なら強さも — にする
- 向きは案件の期間で書く（強まる / 横ばい / 弱まる）。Porter は今の水準だけでなく変化を見るよう求めている
- 5 つの力を平均して点数にしない。影響の大きい 1〜2 個の力が利益を決めることが多い

## 5. 力ではない要因を分けて書く

成長率、技術・イノベーション、規制・政策、補完財は、力ではない（Porter 2008）。どれも 5 つの力を通じて利益に影響する。

| 要因 | よくある影響の仕方 |
|---|---|
| 成長率 | 高い成長は参入を呼び、売り手を強くする。成長率が高い = 魅力的、ではない |
| 技術 | 代替品を生む、参入障壁を上げる・下げる |
| 規制・政策 | 参入障壁、買い手の力（公共調達）、競争の形を変える |
| 補完財 | 一緒に使うものの価格や普及が需要を決める。参入障壁を上げることも下げることもある（Brandenburger & Nalebuff の補完財の見方） |

表に「どの力を通じて影響するか」を書く。6 本目の力として力の表に足さない。

## 6. 利益の実績と突き合わせる

構造の読みが正しいかは、業界の利益の実績で確かめる。

- 同業の営業利益率と ROIC を複数年並べる（competitor-benchmark、financial-analysis の ID）。一年だけでは景気の波と区別できない
- 業界ごとの ROIC の差は長い期間でもあまり縮まらない（McKinsey の長期の ROIC の分析）。だから業界の比較に使える
- 読みと実績が合わないときは、そのまま書く。強さを書き換えて合わせない。合わない理由（定義の範囲、景気の局面、特定の一社）を探す
- 実績がない（— ばかり）なら、総合判断は弱いと書く

なぜここで突き合わせるか: 要因の積み上げだけだと、もっともらしい話になりやすい。利益の実績は、読みが外れていないかの一番の点検になる。

## 7. 全体の構造と位置どり（ゲート2）

- 3〜5 行で、どの力が業界の利益を決めているか、どちらに向かっているかを書く
- 位置どりの論点を問いの形で書く: 力の弱いところに立てるか / 力を自分に有利に変えられるか / 構造の変化を先取りできるか
- 総合判断は人が決める。ここで止まり、決まったら D-xxx で残す

## 8. 渡す

- 業界の定義は market-sizing に渡し、同じ範囲で市場を測る
- 構造的に魅力のあるセグメントと位置どりの論点は option-longlist へ
- 総合判断は option-evaluation の魅力度・リスクの列の材料になる
- 足りない同業の利益率は competitor-benchmark で足す
