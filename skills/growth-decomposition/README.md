# growth-decomposition

## 概要

セグメント別の売上の推移（financials.csv）と、過去の市場成長率、期間中の買収を渡すと、過去の成長を「市場成長」「M&A」「シェア・残差」に分けて返す。金額（億円）と年率（pt）の両方で出し、成長企業の平均的な内訳（McKinsey 2017: 市場 5.4% / M&A 2.5% / シェア 0.8%）と並べる。

## 利用メリット

- 「この会社は何で伸びてきたか」に、数字で答えられる。
- 市場並みに伸びただけか、買って伸びたか、取って伸びたかが分かる。将来のシェアの見込みを置くときの材料になる。
- セグメントの組み替えをまたぐ期間を自動で分けるので、不連続な数字で成長率を出さずに済む。

## 利用シーン

- 現状分析（お題A の 1 週目）で、過去の成長の質を確かめたいとき
- gap-bridge でシェアのレバーを置く前に、過去にシェアで伸びた実績があるかを見たいとき
- M&A の効果を、オーガニックの成長と分けて見たいとき（お題D）

依頼の例: 「この会社、何で伸びてきたの？」「M&A 抜きだと何%？」「市場並みに伸びてるだけ？」

## 使い方

company-financials で financials.csv ができた後に入る。結果は gap-bridge と storyline の材料になる。

1. 期間、過去の市場成長率、期間中の買収（セグメント、年度、売上寄与）を確かめる。過去の市場成長率がなければ — のまま進める。
2. スキルが `scripts/decompose.py` を回す。組み替えをまたぐ期間は、組み替え前と組み替え後に分け、合算行も出す。
3. スキルが `facts/growth-decomposition.md` を書き、台帳に推定の行を足す。
4. スキルは止まり、期間の選び方と市場成長率の扱いを人に返す。

## 人が決めること

- 期間と端の年（FY2020 のような落ち込みの年を端にするか）
- 過去の市場成長率を何で置くか（置けなければ — のまま）
- 残差を「シェア獲得」と呼んでよいか（受注や顧客数など別の証拠があるときだけ）

## よく外す点

- セグメントの組み替えの前後を、そのままつないで成長率を出す
- 買収した事業の売上をオーガニックに入れる。または買収金額から売上寄与を推し量る
- 残差を全部シェア獲得と呼ぶ
- 落ち込みの年を期首にして、成長を大きく見せる

詳しくは [references/pitfalls.md](references/pitfalls.md)。

## 具体例

| 期間 | 連結の年率 | M&A | オーガニック |
|------|----------|-----|-----------|
| FY2016→FY2025（9 年） | 4.5% [F-009] | 0.4pt [F-365] | 4.1% [F-366] |

FY2021 の組み替えをまたぐ産業機械部品と電子部品は、通しの期間では分解せず、合算行と 2 期間に分けた。過去の市場成長率は公開資料にないので —。
