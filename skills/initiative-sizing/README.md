# initiative-sizing

## 概要

ロングリストのレビューを通った打ち手を渡すと、施策カード（I）が返る。カードには、対象市場 × 上乗せシェア × 立ち上がりで見積もった年次の上乗せ売上と、年次の投資と、確度が載る。買収は買収先の売上を連結する年から数える。計算は `scripts/sizing.py` が行い、結果を `05-initiatives.csv` と台帳の I-xxx に書く。確度は人が決める。

## 利用メリット

- 立ち上がりの曲線（S 字か直線）と開始年を置くので、初年度から満額になる見積もりを防げる
- 売上を成り行きへの上乗せで出すので、市場成長を二重に数えない
- 入力は台帳の ID で渡すので、どの数字が仮置きで、いつまでに差し替えるかが残る
- 投資の年次表が同時に出るので、そのまま capital-capacity で資金の手当てを確かめられる

## 利用シーン

依頼の例: 「この打ち手、いくらになる？」「施策ごとに売上見積もって」「施策カード作って」「立ち上がりも入れて年次で出して」

- お題A: EV 熱マネ部品の拡販、半導体装置向けの能力増強、海外の同業買収などを、FY2030 までの年次で見積もる
- お題B: ミックス改善や撤退による売上の増減を見積もる（撤退はマイナスのシェアではなく、別のカードで扱う）
- お題C: 新規参入の売上を、立ち上がりの遅い S 字で見積もる

## 使い方

**いつ使うか:** option-longlist のレビューで sizing に回す打ち手が決まった後。次は capital-capacity と option-evaluation。

1. 回す打ち手ごとに I-xxx を振る
2. 市場規模、市場成長率、上乗せシェア、買収先の売上、投資総額を台帳に登録する（仮置きには差し替え期限）
3. `05-initiative-inputs.csv` に、値ではなく台帳の ID を書く。確度は — のまま
4. 先輩と一緒に前提（市場、上乗せシェア、開始年、立ち上がり年数、投資）を確かめる
5. `python3 skills/initiative-sizing/scripts/sizing.py --ledger facts/facts.csv --inputs 05-initiative-inputs.csv --from FY2026 --to FY2030 --out-csv 05-initiatives.csv --out-md /tmp/05-initiatives.tables.md --append-ledger --today YYYY-MM-DD`
6. 確度（高/中/低）を人に決めてもらい、入力に書いて回し直す
7. `templates/initiatives.md` に表を貼り、`05-initiatives.md` にする

## 人が決めること

- 上乗せシェア、開始年、立ち上がり年数、投資の前提（先輩と一緒に決める）
- 確度（高/中/低）とその理由。スキルは — のまま渡す
- 施策どうしが重なるときに、どちらで数えるか

## よく外す点

- 初年度から満額を計上する
- 成り行きに含まれる市場成長まで施策の売上に数える（シェア全体を掛けてしまう）
- 売上だけ見積もり、投資を置かない
- 確度を作業者が決めてしまう
- 工業会の市場の定義と、会社の売上の定義の違いを見ない

詳しくは [references/pitfalls.md](references/pitfalls.md)。

| I-002 | 半導体製造装置向け部品の能力増強 | 230.8 億円 [I-002] | 中 |
| I-005 | 産業用センサーの海外展開（提携） | 135.3 億円 [I-005] | 中 |
| I-006 | 海外同業の中規模買収 | 420.0 億円 [I-006] | 低 |
