# 何を聞いてから始めるか

## ファイルで確かめること

| 確かめること | どこを見るか | ないときの扱い |
|-------------|-------------|---------------|
| sizing に回す打ち手 | decisions.md の D-xxx、04-options.md | レビューが先。決まっていなければ始めない |
| 成り行き（S）の作り方 | 03-gap-bridge.md | 成り行きに何が入っているか（市場成長、既存シェア）を確かめ、上乗せ分だけを見積もる |
| 見積もり期間と目標年度 | 00-target-spec.md | `--to` は目標年度にそろえる |
| 対象市場の規模と成長率 | facts/market-sizing.md、facts/facts.csv | なければ market-sizing に戻るか、仮置きで登録して期限を付ける |
| 買収の想定（売上、買収額、連結の開始年） | 04-options.md、facts/facts.csv | 仮置きで登録。買収額の倍率（売上の何倍か）も根拠を書く |
| 投資の総額と時期 | 中計の投資計画、有報の設備投資 | 分からなければ — で登録し、capital-capacity で — のまま扱う |

## 先輩と一緒に決めること（手順 4 で止まる）

1. 上乗せシェアの幅: 「この会社が過去 5 年で取れたシェアの増分と比べて妥当か」
2. 開始年と立ち上がり年数: 「量産の立ち上げに何年かかってきたか」（お題A の精密部品メーカーは前中計で EV 熱マネの立ち上がりが 1 年後ろ倒し）
3. 立ち上がりの形: 新規顧客の開拓は S 字、既存顧客への能力増強は直線が目安
4. 投資を置く年度: 売上の 1〜2 年前に置くのが普通

## 入力 CSV の列

| 列 | 中身 |
|----|------|
| `id` | I-001 の形。台帳の次の空き番号 |
| `initiative` | 施策の名前 |
| `option_id` | もとの O-xxx |
| `method` | `market_share`（市場 × シェア）/ `acquisition`（買収） |
| `market_ref` | 対象市場の規模の ID（億円・兆円・百万円） |
| `growth_ref` | 市場成長率の ID（%） |
| `share_gain_ref` | 上乗せシェアの ID（pt か %）。成り行きのシェアは含めない |
| `acq_revenue_ref` | 買収先の売上の ID（買収のとき） |
| `base_year` | 市場規模の年度。空なら台帳の period から取る |
| `start_year` | 売上が立つ最初の年度（FY2027） |
| `ramp_years` | 満額に届くまでの年数 |
| `curve` | `s` / `linear` / `step` |
| `investment_ref` | 投資総額の ID |
| `invest_from` / `invest_to` | 投資を置く年度の範囲 |
| `invest_weights` | 年度ごとの配分（例 3:4:3）。空なら均等 |
| `confidence` | 高 / 中 / 低 / —。人が決めるまで — |
