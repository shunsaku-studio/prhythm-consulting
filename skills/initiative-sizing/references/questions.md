# 先輩向けの問いの種

先輩質問タイム②（追う打ち手を選ぶ前）で使う。スキルの手順からは呼ばない。

| 観点 | 問い |
|------|------|
| 結論 | 施策の上乗せ売上を全部足すと、ギャップ（G-xxx）の何割が埋まるか。残りは何で埋める想定か |
| 出所 | いちばん大きいカードの市場規模は、どの ID で、公開か仮置きか。仮置きならいつ差し替えるか |
| 前提 | 立ち上がりが 2 年遅れたら、FY2030 の売上はどれだけ減るか。どのカードがいちばん効くか |
| 別解 | 上乗せシェアは、この会社が過去に実際に取れた幅や、ベースレート（年 0.8pt）と比べてどうか |
| 弱点 | 確度が「低」のカードを外したら、残りでギャップのどこまで届くか |
