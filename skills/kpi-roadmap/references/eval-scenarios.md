# eval-scenarios — 評価の場面

## お題A（主）: 北辰工業、ゲートと撤退基準の確定の前

- 入力: `cases/hokushin/` の `model/model.csv`、`model/sensitivity.md`、`07-kpi-tree.md`、`05-initiatives.md/.csv`、`decisions.md`（追う打ち手の決定がある）
- 状況: 前中計で EV 熱マネジメントの立ち上がりが 1 年遅れ、M&A は価格が折り合わず見送った。社長は「高値づかみはしない」と発言している
- 仕込まれやすい問題:
  - 「FY2027 に見直し」だけのゲート
  - 買収のゲートに価格の上限（撤退基準）がない
  - 量産投資の発注の後にゲートがある
  - 受注のデータを、アウトサイドインの段階で取れる前提にしている
- 期待する振る舞い:
  - KPI 目標の売上の年次の値をモデルから取り、K- を振る
  - 量産投資の前と買収契約の前にゲートを置き、指標を感応度の上位から選ぶ
  - 買収のゲートに価格の上限を撤退基準として書く（価格規律の発言を根拠に）
  - 閾値を決めずに「人が決めること」に残し、マネージャーと決めて D- を残す
  - 社内データが要るゲートのデータを、前提と未確認事項に回す
  - `render_roadmap.py` の「直すこと」が 0 件、number-audit がエラー 0 件

## 変化形 1: 資本効率（お題B みなと食品）

- 売上の施策より、政策保有株式の売却や事業の撤退がゲートになる。
- 見るところ: KPI 目標に ROE と ROIC を年度別に置くか。事業の撤退基準を、ROIC と WACC の差で書くか。

## 変化形 2: 新規参入（お題C 東邦電機）

- 工場向けエネルギー管理サービスの立ち上げ。最初の顧客の獲得と継続率がゲートになる。
- 見るところ: 参入の約束（専任チームの設置、設備）の前にゲートを置くか。撤退基準を顧客数や継続率で具体的に書くか。
