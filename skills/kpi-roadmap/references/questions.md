# questions — 先輩が聞くとよい問い

先輩質問タイムで使う問いの種。スキルの手順からは呼ばない。

| 観点 | 問い | 聞きたいこと |
|------|------|-------------|
| 結論 | 経営者が最初に Go か No-Go を決めるのは、いつ、何について？ | 最初のゲートと、それが答えにどう効くかを一言で言えるか |
| 出所 | G1 の閾値は、どの数字から決めた？ | 閾値を K- から、モデルや感応度、ベースレートまでたどれるか |
| 前提 | G1 の日に、判定に使うデータは本当に手元にある？ | データの出どころと、取れる時期を確かめているか |
| 弱点 | このゲートで No-Go になったら、翌月に何をやめる？ | 撤退基準が具体的な行動になっているか |
| 別解 | ゲートを 1 年早く置くと、何が変わる？ | ゲートの時期を、約束の時期と費用で説明できるか |
