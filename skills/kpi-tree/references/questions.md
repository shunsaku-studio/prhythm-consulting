# questions — 先輩が聞くとよい問い

先輩質問タイムで使う問いの種。スキルの手順からは呼ばない。

| 観点 | 問い | 聞きたいこと |
|------|------|-------------|
| 結論 | 目標に届くかを一番左右するノードはどれ？ | ツリーの中で目標の達成を一番左右するところを一つ挙げられるか |
| 出所 | 成り行きのセグメント売上を足すと、連結の成り行きになる？ ならないなら、なぜ？ | 定義と出所の違いを説明できるか |
| 前提 | — のまま残したノードのうち、分かれば結論が変わるものはどれ？ | 未確認のノードの重みを把握しているか |
| 弱点 | ROIC のツリーで、M&A をすると悪くなるノードはどれ？ | 売上の伸びと資本効率の引き換えを理解しているか |
