# leadership-lens

## 概要

経営者の公の発言（決算説明会、統合報告書のトップメッセージ、株主総会、インタビュー）を渡すと、日付と出典を付けた一覧にし、「本人発言」「メディア解釈」「推測」のラベルで分ける。テーマごとにまとめ、繰り返し出てくる考えから「譲れない線」の候補を仮説として出す。どの候補を提案の前提に置くかは、マネージャーと一緒に決める。成果物は `facts/leadership.md` である。仮の型（provisional）なので、テンプレート 1 枚とよく外す点だけを置いている。

## 利用メリット

- 目標の出どころ（誰が、いつ、どの場で言ったか）が分かる。target-math の定義チェックにそのまま使える。
- 本人の言葉と、記者の解釈を分けて扱える。提案が記事の見出しに引きずられない。
- 経営者が公に約束したこと、否定したことを先に押さえるので、提案の筋が経営者の言葉と食い違わない。

## 利用シーン

- 目標が説明会の発言として出てきて、資料に書かれていないとき
- 提案の二本のレーンのどちらを前に出すかを考える前に、経営者が公に言ってきたことを確かめたいとき

依頼の例: 「社長の発言を整理して」「経営者が何を大事にしているか見て」「社長の譲れない線は？」

## 使い方

お題A の 1 段目（目標を仕様にする）で、target-math、midterm-plan-reader と並べて使う。

1. 経営者の名前と役職、期間（既定は直近 2〜3 年）、手元の資料とページを渡す。
2. スキルが発言を集め、1 行に 1 発言で日付・場・ラベル・要約・テーマ・出典を書く。
3. スキルが発言に出てくる数字（目標値、ROE、配当性向など）を台帳に登録する。
4. スキルがテーマごとにまとめ、譲れない線の候補を仮説として出して止まる。
5. マネージャーと一緒に、どの候補を提案の前提に置くか、どれをクライアントに確かめるかを決める。決定は `decisions.md` に D- の ID で残す。

守ること:

- 公の場での発言と行動だけを扱う。私生活、健康、家族には触れない。資料にあっても要約しない。
- 性格の診断めいた断定（「慎重な性格」など）をしない。何を、いつ、どこで言ったかを書く。
- 引用は 1 行に短い一句まで。それ以外は自分の言葉で要約し、出典とページを書く。有料記事やメディア記事は要約と出典だけにする。

## 人が決めること

- 譲れない線の扱い（ゲート、△ 一緒に決める）。前提に置く / クライアントに確かめる / 外す、を候補ごとに決める。
- メディア解釈しか根拠のない候補を、提案で使うかどうか。

## よく外す点

- 記事の見出しや記者の解釈を、本人の発言として扱う。
- 一度だけの発言を、譲れない線と決めつける。
- 発言の日付を書かず、考えの変化を見落とす。

詳しくは [references/pitfalls.md](references/pitfalls.md)。

## 具体例

| # | ラベル | 要約 |
|---|-------|------|
| 3 | 本人発言 | 前中計では価格の規律を守って M&A を見送った。「高値づかみはしません」（2026-05-15） |
| 9 | メディア解釈 | 記者は「海外の同業買収を視野に入れているとみられる」と書いた（本人の発言ではない） |
| 10 | 本人発言 | 自動車部品の比率は 50% [F-052] を切りたい（2026-07-02） |

譲れない線の候補のうち、価格の規律と配当性向 35% [F-015] の維持を提案の前提に置いた（D-002）。

## 先輩が聞くとよい問い

[references/questions.md](references/questions.md) に問いの種を置いている。スキルの手順からは呼ばない。

- この候補は本人の言葉か、記者の解釈か。本人は何回、どの場で言っているか。
