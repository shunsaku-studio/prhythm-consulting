# market-sizing

## 概要

市場の定義、業界団体の市場規模と成長率の見通し、自社の定義に合う割合、ボトムアップの要因を渡すと、目標年の市場規模を幅（低・基準・高）で返す。トップダウンとボトムアップを突き合わせ、差が大きければ注意を出す。自社の推定シェアも出す。お題A では、ここで決めた成長率が gap-bridge の成り行きの前提になる。

## 利用メリット

- 「市場は何%で伸びるか」を、定義と幅と出典の付いた形で決められる。
- 業界見通しの下方修正を見込んだ低ケースが、最初から入る。
- 2 つの方向から見積もるので、定義のずれや要因の置き違いに気づける。

## 利用シーン

- gap-bridge の前に、成り行きの市場成長率を決めたいとき（お題A の 1 週目）
- 業界団体の数字を 1 つだけ引いて、そのまま使いそうになったとき
- 新しい市場の大きさを見たいとき（お題C）

依頼の例: 「市場はどれだけ伸びる？」「工業会の数字そのまま使っていい？」「この市場、何%成長で置けばいい？」

## 使い方

**いつ使うか:** company-financials と growth-decomposition の後、gap-bridge の前に入る。

1. セグメントごとに市場の定義を書き、自社のセグメント売上との違いを書く。
2. 業界団体の市場規模と成長率、自社の定義に合う割合（低:基準:高）、ボトムアップの要因を集める。分からない値は — か仮置き。
3. スキルが `scripts/market_sizing.py` を回し、トップダウンとボトムアップの幅と突き合わせを出す。
4. スキルが `facts/market-sizing.md` を書き、台帳に行を足す。
5. スキルは止まり、成り行きに使う成長率をマネージャーに決めてもらう。

## 人が決めること

- 成り行きに使う成長率（低・基準・高のどれか）。このゲートで確定し、decisions.md に残す
- 業界団体の市場のうち、自社の定義に合う割合の置き方
- 仮置きの値をいつまでに差し替えるか

## よく外す点

- 定義があいまいなまま、1 つの数字だけを出す
- 業界団体の市場の定義を、自社の売上の定義と同じものとして扱う
- 何度も下方修正された見通しを、そのまま基準ケースにし、幅も上下対称に置く
- トップダウンとボトムアップの差を、要因をいじって消す

詳しくは [references/pitfalls.md](references/pitfalls.md)。
