# midterm-plan-reader

## 概要

中期経営計画と最終年度の振り返り資料を渡すと、目標・実績・達成状況・重点施策・投資計画を 1 枚の表にまとめる。目標に M&A の上積みが入っていればオーガニックの目標と分け、計画・振り返り・有報の間で定義がずれていないかを書く。達成率と進捗率はスクリプトで出す。成果物は `facts/midterm-plan.md` と台帳の行である。仮の型（provisional）なので、テンプレート 1 枚とよく外す点だけを置いている。

## 利用メリット

- 会社が自分で約束したことと、実際に届いたことが一目で分かる。提案の出発点がずれない。
- M&A 込みの目標をオーガニックと分けるので、未達の理由（買収が実行できなかったのか、本業が伸びなかったのか）を分けて話せる。
- 数字に ID が付くので、target-math や gap-bridge がそのまま使える。

## 利用シーン

- 新しい目標の話の前に、前の中計がどうだったかを押さえたいとき
- 中計の目標と有報の実績が合っているかを確かめたいとき

依頼の例: 「中計を整理して」「前の中計、何が未達だった？」「中計の目標と実績を並べて」

## 使い方

**いつ使うか:** お題A の 1 段目（目標を仕様にする）で、target-math、leadership-lens と並べて使う。お題B では資本政策の目標を拾うために使う。

1. 中計の資料、最終年度の振り返り資料、ページを渡す。
2. スキルが目標を原文どおりに並べ、M&A の上積みや「以上」などの注記を拾う。
3. スキルが目標と実績を CSV にし、`plan_check.py` で達成率と進捗率を出す。
4. スキルが重点施策と投資計画（計画と実行）を表にし、会社自身の説明を要約して出典を付ける。
5. 次の中計の方針（公表時期、期間、方針）を書き、target-math の定義チェックに渡す。

## 人が決めること

止まって決めてもらう場面はない（単独度 ◎）。次は人が確かめる。

- 会社の説明（「EV 化の遅れで 1 年後ろ倒し」など）をそのまま受け取るか、別の資料で裏を取るか。
- 振り返り資料の実績と有報の数字の定義が違うとき、どちらを使うか。

## よく外す点

- M&A の上積みを含む目標を、オーガニックの目標として読む。
- 計画・振り返り・有報で定義がずれているのに、同じ数字として並べる。
- 未達の理由について会社の説明を事実として書く。

詳しくは [references/pitfalls.md](references/pitfalls.md)。

## 具体例

前中計の売上目標 2,300.0 億円 [F-017] は M&A の上積み 150.0 億円 [F-018] を含んでいた。実績は 2,000.0 億円 [F-001] で、達成率は 87.0% [F-019]。オーガニック目標 2,150.0 億円 [F-022] にも届いていない。M&A 枠 120.0 億円 [F-048] は実行 0.0 億円 [F-049] だった。

## 先輩が聞くとよい問い

[references/questions.md](references/questions.md) に問いの種を置いている。スキルの手順からは呼ばない。

- 売上の未達 300 億円のうち、M&A が実行できなかった分と本業の分はそれぞれいくらか。
