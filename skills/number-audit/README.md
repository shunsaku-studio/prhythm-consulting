# number-audit

## 概要

案件フォルダを渡すと、すべての数字をファクト台帳 `facts/facts.csv` と突き合わせ、食い違いの一覧を返す。見るのは、台帳にない ID、台帳と違う値、出典 ID のない数字、期限切れの仮置き、社外に出す成果物に入った社外秘の値、Excel モデルの直打ちである。点検はスクリプト `scripts/audit.py` が行う。結果は `reviews/number-audit.md` に書き出す。

## 利用メリット

- 「この数字どこから？」に、ID で即答できる状態を保てる。
- 上流で数字が変わったとき、古い値が残っている場所を漏れなく拾える。
- 仮置きのまま期限が過ぎた値を、デッキに載る前に見つけられる。
- 社外秘の値が社外向けの成果物に紛れ込むのを止められる。

## 利用シーン

- マネージャーや先輩質問タイムに成果物を出す前
- 仮置きを差し替えた、モデルを回し直した、など数字が変わった後
- 最終メッセージを確定する前（`--strict` で最終点検）

依頼の例: 「数字の裏取りして」「出典のない数字ない？」「仮置き残ってない？」「デッキに出す前に点検して」

## 使い方

**いつ使うか:** どの段の後でも使える。お題A では 10 段目（ストーリー）で storyline と組で使う。storyline が書いた `deliverables/storyline.md` は、ここでエラー 0 件になってから上に出す。

1. 案件フォルダと今日の日付を渡して、スクリプトを回す。

   ```bash
   python3 skills/number-audit/scripts/audit.py case \
     --today 2026-11-12 --out case/reviews/number-audit.md
   ```

   レポートは `reviews/` に置く。`reviews/` は点検の対象外なので、レポート自身が点検に引っかからない。
2. レポートのエラーを、4 つの直し方に振り分ける。ID を付ける / ファイルの値を台帳に合わせる / 台帳の行を直す / `—` にして未確認事項に回す。
3. 機械的に直せるものは直す。二つの出典で値が違う、仮置きの期限が切れた、など選ぶ必要があるものは、人に聞く。
4. エラーが 0 件になるまで回し直す。最終メッセージを確定する前に `--strict` を付けてもう一度回す。
5. 直した内容を `reviews/number-audit-triage.md` に残す（型は [templates/number-audit-triage.md](templates/number-audit-triage.md)）。

### エラーと警告の読み方

| 種類 | 意味 | どうするか |
|------|------|-----------|
| エラー | たどれない数字。台帳にない ID、台帳と違う値、台帳の行の不備、期限切れの仮置き、モデルの直打ち。`deliverables/` では、出典 ID のない数字と社外秘の値もエラー | 上に出す前に直す |
| 警告 | 作業中なら許すもの。作業ファイル（`03-gap-bridge.md` など）の出典 ID のない数字、`deliverables/` の数字が仮置きか `—` に依存していること | `deliverables/` に載せる前に直す。`--strict` を付けるとエラーとして数える |

`deliverables/` だけ厳しいのは、そこがチームの外に出るからだ。作業ファイルなら粗い数字が 1 日残ってもよい。成果物ではよくない。

## 人が決めること

- 二つの資料で値が違うとき、どちらを採るか
- 期限切れの仮置きを、延ばすか、推定に差し替えるか、`—` にして外すか
- 成果物から数字を外すかどうか
- 社外秘の値を成果物から外すか、クライアントの了解を取って載せるか

決めたことは `decisions.md` に `D-` の ID で残す。スキルは決めない。

## よく外す点

- 値が同じでも定義が違う数字を見逃す（連結とセグメント、オーガニックと M&A 込み）。スクリプトは定義を比べない。
- 単位の付かない数字（表の中の素の「2,000」など）は、出典 ID がなくても拾われない。表には単位を見出しではなくセルに書くか、ID 列を置く。
- 台帳を直して数字を合わせる。正しいのが台帳かファイルかを確かめずに、エラーを消すために台帳を書き換えない。
- 会話の中で計算し直して値を埋める。計算が要るなら、その値を作ったスキルのスクリプトを回し直す。

詳しくは [references/pitfalls.md](references/pitfalls.md)。

## 具体例

最終の点検（2026-11-13）は、台帳 629 件、点検したファイル 38 件でエラー 0 件。警告 15 件は、デッキの数字が仮置きに依って立つという警告で、対応表に理由を書いて残した。capital-capacity の合計の計算式が言葉だけで ID をたどれなかった点も、この点検で見つけて直した。
