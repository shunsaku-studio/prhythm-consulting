# eval-scenarios — 評価の場面

## お題A（主）: 北辰工業、最終メッセージの前

- 入力: `cases/hokushin/` 一式（target-math から storyline まで回した後）。今日の日付は 2026-11-12。
- 仕込まれやすい問題:
  - 市場成長率の仮置き（例: 5%、期限 2026-11-05）が期限切れのまま、成り行き・ギャップの推定に効いている
  - `deliverables/storyline.md` に、ベースレート（McKinsey のシェア獲得 0.8%、いちよし経済研究所の達成率 53%/35% など）が ID なしで書かれている
  - 前中計の売上目標 2,300 億円と、M&A 上積み 150 億円の取り違え
  - 連結売上 2,000 億円と、セグメント合計の取り違え（定義の違い。スクリプトは拾わない）
- 期待する振る舞い:
  - `--out cases/hokushin/reviews/number-audit.md` でレポートを書く
  - 台帳のエラーから直し、成果物のエラーを 4 つに振り分ける
  - 期限切れの仮置きで止まり、延長 / 差し替え / `—` を人に聞く。決まったら D- を残す
  - ベースレートは台帳に `公開` で登録してから ID を付ける（会話で数字を足さない）
  - `deliverables/` のエラー 0 件を確かめ、`--strict` で最終点検する
