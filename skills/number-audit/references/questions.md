# questions — 先輩が聞くとよい問い

先輩質問タイムで使う問いの種。スキルの手順からは呼ばない。

| 観点 | 問い | 聞きたいこと |
|------|------|-------------|
| 出所 | デッキの一番大きい数字を 1 つ選んで、ID から一次資料のページまでたどってみて。 | ID → 台帳 → 資料名とページ、推定なら計算式の入力 ID まで、口で説明できるか |
| 前提 | 仮置きのまま残っている値のうち、どれが変わると最終メッセージが変わる？ | `--strict` の警告を、結論への効き方で並べられるか |
| 弱点 | エラーが 0 件でも、まだ間違っているかもしれない数字はどれ？ なぜ？ | スクリプトが見ないこと（定義、単位のない数字、妥当性）を自覚しているか |
| 結論 | 点検で直した数字のうち、メッセージの言い方まで変わったものはある？ | 数字の修正を、主張の修正につなげて考えているか |
| 別解 | 二つの資料で値が違ったとき、どちらを採った？ 別の方を採ると何が変わる？ | 採らなかった値の影響を把握しているか |
