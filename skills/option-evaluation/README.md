# option-evaluation（仮の型）

## 概要

見積もり済みの施策（I）を渡すと、効果、実現性、必要資本、効果が出る早さ、リスク、中計・経営者の譲れない線との整合の 6 つの軸で並べた評価マトリクスが返る。重みは人が決める。`scripts/score.py` は加重合計を入力の順に出し、重みを少し動かすと上下が入れ替わる組を示すだけで、順位は付けない。どれを追うかは人が決める。

## 利用メリット

- 追う打ち手を選ぶゲートの前に、比べる材料が一枚にそろう
- 点数の横に根拠の ID があるので、なぜその点数かを質問タイムでたどれる
- 重みを動かすと結論が変わる組が分かり、議論すべき点が絞れる

## 利用シーン

依頼の例: 「打ち手を比べて」「どれを追うか決めたいので材料並べて」「評価マトリクス作って」

- お題A: B2B の精密部品メーカー（売上 2,000 億円、自動車部品・産業機械部品・電子部品の 3 事業）の自前の施策と海外の同業買収を、資本の制約と「高値づかみはしない」の線も含めて比べる
- お題C: 既存事業が成熟した産業機器メーカー（工場向けエネルギー管理サービスへの参入を検討）の参入方式（自前・提携・買収）を比べる

## 使い方

initiative-sizing と capital-capacity の後、追う打ち手を選ぶゲート（その前に質問タイム②）の前に使う。

1. `templates/evaluation-matrix.md` を 04-options.md の末尾に「評価マトリクス」として写す
2. 施策ごとに、軸ごとの根拠を ID 付きで書いてから、1〜5 の点数を付ける（どの軸も大きいほど良い）
3. 重みを人に決めてもらう
4. `python3 skills/option-evaluation/scripts/score.py 04-evaluation-matrix.csv --weights impact=30,feasibility=20,...` で加重合計を出す
5. 結果を貼り、人が追う施策と前に出すレーンを決める（decisions.md に D-xxx）

## 人が決めること

- 軸の重み（点数を見る前に決める）
- 追う施策と、前に出すレーン
- 経営者の譲れない線に触れる施策を外すかどうか

## よく外す点

- 点数を見てから重みを決める
- 点数に根拠がない
- 軸の向きがそろっていない（必要資本やリスクは大きいほど悪い）
- 加重合計の小さな差を本当の差として扱う
- 譲れない線に触れる施策を、断りなく外す

詳しくは [references/pitfalls.md](references/pitfalls.md)。

## 具体例

重み（効果 25、実現性 20、必要資本 20、早さ 10、リスク 15、整合 10）を点数の前に決めた（D-011）。加重合計は I-001 が 3.95、I-006 が 2.70 で、重みを ±10 動かしても入れ替わる組はなかった。I-006 は価格の規律に触れるかが未確認（—）のまま示し、条件付きで追うと決めた（D-012）。
