# よく外す点

## 1. 点数を見てから重みを決める

- 悪い例: 点数を付けたあと、推したい施策が上に来るように重みを調整する
- 良い例: 重みを先に人が決め、D-xxx に残す。点数は後で付ける

## 2. 点数に根拠がない

- 悪い例: 「効果 4、実現性 3」とだけ書く
- 良い例: 「効果 4: FY2030 の上乗せ売上 [I-001]、ギャップ [G-001] の 1 割強」のように、根拠と ID を点数の横に置く

## 3. 軸の向きがそろっていない

- 悪い例: 必要資本の欄に「大きいほど 5」と「小さいほど 5」が混ざる。加重合計の意味がなくなる
- 良い例: どの軸も「大きいほど良い」にそろえる（必要資本は 5 = 小さい、リスクは 5 = 小さい）

## 4. 加重合計で順位を付けて決めたことにする

- 悪い例: 3.50 と 3.40 の差で「I-002 を優先」と書く
- 良い例: 順位は付けない。差が小さい組と、重みで入れ替わる組を示し、人が議論して決める

## 5. 譲れない線に触れる施策を黙って外す

- 悪い例: 「高値づかみはしない」に触れそうな買収を、表から消す
- 良い例: 表に残し、譲れない線を × か —（未確認）にして、外すかどうかを人に委ねる。本人発言かメディア解釈かも書く

## 6. 確度と点数を混ぜる

- 悪い例: 作業者が実現性の点数で、人が決めた確度を上書きする
- 良い例: 実現性の根拠に、人が決めた確度（D-xxx）をそのまま引く
