# 先輩向けの問いの種

先輩質問タイム②（追う打ち手を選ぶ前）で使う。スキルの手順からは呼ばない。

| 観点 | 問い |
|------|------|
| 結論 | 加重合計の差がいちばん小さい組を、何で決めるか。マトリクスの外にある判断材料は何か |
| 出所 | 効果と必要資本の点数は、どの I-xxx と C-xxx から付けたか |
| 前提 | 重みをどう決めたか。点数を見る前に決めたか。重みを動かすと入れ替わる組はどれか |
| 別解 | 外した施策のうち、レーン 2 として残しておく価値があるのはどれか |
| 弱点 | 譲れない線が — のままの施策はどれで、誰に、何を確かめれば ○ か × になるか |
