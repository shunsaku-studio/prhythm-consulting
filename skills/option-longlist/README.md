# option-longlist

## 概要

ギャップ（G）と制約を渡すと、ギャップを埋めうる打ち手候補（O）を網羅したロングリストが返る。打ち手は「既存市場か新規市場か × 既存製品か新規製品か × 自前か提携か買収か」のグリッドに、価格・ミックスとポートフォリオ（撤退・売却・縮小）の行を足して並べる。各打ち手には、どのギャップを埋めるか（G-xxx）と、中計に則るレーン 1 か中計の外側のレーン 2 かを書く。空いたマスは埋めずに「空欄」と示す。

## 利用メリット

- 思いついた数案で止まらず、検討していない領域が目で見て分かる
- 空欄を「検討していない」と「検討して該当なし」に書き分けるので、レビューで抜けを指摘しやすい
- M&A や市場の選び直しを最初から候補に入れるので、二本目のレーンの材料が揃う
- 打ち手と G-xxx がつながるので、どのギャップが手薄かがすぐ分かる

## 利用シーン

依頼の例: 「打ち手を洗い出して」「ギャップを何で埋めるか、候補を全部出して」「打ち手の抜け漏れ見て」「M&A も含めて選択肢並べて」

- お題A: 2,447 億円のギャップを、中計の重点施策と、その外側の打ち手で埋める候補を出す
- お題B: ROE を上げる打ち手として、成長だけでなく撤退・売却やミックス改善も並べる
- お題C: 新規参入の入り方（自前・提携・買収）を並べて比べる前の候補を出す

## 使い方

gap-bridge で `03-gap-bridge.md` ができた後に使う。次は initiative-sizing で打ち手を見積もる。

1. `templates/options.md` を `04-options.md` に写し、ギャップと制約（中計の方針、経営者の譲れない線、財務規律）を書く
2. 中計の重点施策、各ギャップ、グリッドの各マスの順に打ち手を考え、1 行 1 案で書く。根拠の数字には台帳の ID を付ける
3. レーン 2 の打ち手（買収、市場の選び直し、撤退）を意識して足す
4. `python3 skills/option-longlist/scripts/coverage.py 04-options.md --gaps 03-gap-bridge.md --write` で網羅グリッドを作る
5. 空欄は、本物の打ち手を足すか、空欄のまま残す。理由があるときだけ「該当なしの判断」に書く
6. レビューに出し、sizing に回す候補を決めてもらう（decisions.md に D-xxx）

## 人が決めること

- sizing に回す打ち手、保留する打ち手、落とす打ち手（レビューで決める。D-xxx）
- 空欄のマスを「該当なし」としてよいか
- 買収を目標に数えてよいか（目標仕様 T-xxx の定義による）
- レーン 1 とレーン 2 のどちらを前に出すか（後のゲートでマネージャーが決める。このスキルでは決めない）

## よく外す点

- 思いついた数案だけで、網羅性がない
- 空いたマスを、もっともらしい文章で埋めてしまう
- 中計の重点施策だけを並べ、レーン 2（M&A、市場の選び直し、撤退）がない
- 打ち手がどのギャップを埋めるかが書かれていない
- 目標がオーガニックの定義なのに、買収を数えている

詳しくは [references/pitfalls.md](references/pitfalls.md)。

## 具体例

網羅グリッド 18 マスに 16 件の打ち手（レーン1 が 8 件、レーン2 が 8 件）を置き、4 マスは先輩が「該当なし」と判断した。初回は coverage.py が 03-gap-bridge.md の必要年率や pt の G- まで「打ち手のないギャップ」と数えたので、「埋めるギャップ」の表の G- だけを見るように直した。
