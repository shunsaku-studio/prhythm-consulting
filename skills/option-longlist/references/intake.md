# 何を聞いてから始めるか

打ち手を考え始める前に、次を確かめる。分からないものは「前提と未確認事項」に書いて先に進む。聞きすぎて止まらない。

## ファイルで確かめること

| 確かめること | どこを見るか | ないときの扱い |
|-------------|-------------|---------------|
| 埋めるギャップの一覧（G-xxx）と大きさ | 03-gap-bridge.md | gap-bridge が先。G がないなら始めない |
| 目標の定義（連結か、M&A 込みか、期限） | 00-target-spec.md、decisions.md | 「M&A 込みかは未確定」と書き、買収の打ち手は残したうえで印を付ける |
| 中計の重点施策 | facts/midterm-plan.md | 中計の資料名とページを直接見る |
| 経営者の譲れない線 | facts/leadership.md | 公の発言だけを使う。本人発言かメディア解釈かを分ける |
| 財務規律（D/E の上限、配当方針など） | facts/facts.csv | ID を付けて制約の表に書く |
| サブ市場ごとの伸び | facts/market-sizing.md、facts/facts.csv | 数字は ID 付きで根拠の列に書く。なければ — |

## 依頼者に聞くこと（1〜2 問まで）

1. 「レーン 2（中計の外側）の打ち手、たとえば撤退や大型の買収も、候補として出してよいか」
   — 出してよいかを聞くのであって、採るかどうかは後のゲートで決まる
2. 「今回、検討の対象から外すと決まっている事業や地域はあるか」

## お題ごとに先に見るもの

| お題 | 先に見るもの |
|------|-------------|
| A 売上成長 | セグメント別のギャップ、サブ市場の伸びの差（お題A の精密部品メーカーなら EV 熱マネ +15% と内燃機関向け −2%） |
| B 資本効率 | ROIC が WACC を下回る事業、政策保有株、遊休資産。成長の打ち手と並べて撤退・売却を出す |
| C 新規参入 | 入り方（自前・提携・買収）の違いが主役。市場は新規で固定される |
