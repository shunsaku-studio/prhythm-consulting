# 手順と、なぜその順か

## 1. ギャップと制約を先に書く

打ち手を考える前に、埋めるギャップ（G-xxx）と制約を 04-options.md の頭に書く。ギャップが分かっていないと、効く打ち手かどうかを判断できない。制約が分かっていないと、経営者が受け入れない案に時間を使う。ただし、制約に触れる案もロングリストには残す。外すかどうかは人が決める。

## 2. 三つの入口から打ち手を出す

| 順 | 入口 | なぜ |
|----|------|------|
| 1 | 中計の重点施策 | レーン 1 の土台。クライアントがすでに持っている案を先に拾う |
| 2 | ギャップごと | 「このギャップは何で埋まるか」と問うと、効き目のある案が出る |
| 3 | グリッドのマスごと | 1 と 2 で出ない領域を探す。網羅はここで担保する |

グリッドから先に始めると、マスを埋めること自体が目的になり、根拠のない案が増える。だから最後に置く。

## 3. 網羅グリッド

| 類型 | 自前 | 提携 | 買収・売却 |
|------|------|------|-----------|
| 市場浸透（既存市場 × 既存製品） | | | |
| 製品開発（既存市場 × 新規製品） | | | |
| 市場開拓（新規市場 × 既存製品） | | | |
| 多角化（新規市場 × 新規製品） | | | |
| 価格・ミックス | | | |
| ポートフォリオ（撤退・売却・縮小） | | | |

- 上の 4 行はアンゾフの成長マトリクス。列は進め方
- 価格・ミックスは、数量を増やさずに売上と利益率を動かす打ち手
- ポートフォリオは、伸びない事業を縮小・売却して資本を伸びる市場に回す打ち手。売上は減るが、ギャップの「質」とレーン 2 の材料になる

## 4. 二本のレーン

| レーン | 中身 | お題A（精密部品メーカー）の例 |
|--------|------|------------|
| 1 中計に則る | 中計の重点施策を延ばし、必要量を示す | EV 熱マネ部品の拡販、半導体装置向け精密部品の能力増強、センサーの海外展開 |
| 2 中計の外側 | ベースレートや資本制約から見て、別の道筋を示す | 海外の同業買収、内燃機関向けの縮小と市場の選び直し |

レーン 2 は「中計が無理だから出す代案」ではない。gap-bridge が赤旗を出したとき（シェア獲得だけで年 5pt 超など）に、何で埋めるかを示す根拠になる。どちらを前に出すかは、後のゲートでマネージャーが決める。

## 5. 網羅を点検する（coverage.py）

マスに O-xxx が入っているかを数えるのは、会話の中でしない。スクリプトに任せる。スクリプトは空欄を埋めない。空欄を見た人が、次のどれかを選ぶ。

- 根拠のある打ち手を足す
- 「該当なしの判断」に理由と判断した人を書く
- 空欄のまま残し、レビューで聞く

## 6. レビューに出す（○）

ロングリストはレビューを通してから sizing に回す。理由は二つある。sizing は 1 案ごとに市場規模とシェアの前提を置く重い作業で、回す案を絞らないと時間が足りない。そして、どれを回すかは判断で、スキルが決めることではない。決めた結果は decisions.md に D-xxx で残す。
