# 先輩向けの問いの種

先輩質問タイム②（追う打ち手を選ぶ前）で使う。スキルの手順からは呼ばない。

| 観点 | 問い |
|------|------|
| 結論 | ギャップがいちばん大きい G-xxx に効く打ち手はどれで、それだけで埋まりそうか |
| 出所 | レーン 2 の打ち手は、どの事実（ID）や本人発言から出てきたか。メディアの解釈を混ぜていないか |
| 前提 | 目標が「オーガニックのみ」に決まったら、このリストのどの打ち手が消えるか |
| 別解 | 空欄のマスのうち「該当なし」にしたのはどれで、その理由は何か。理由が弱いマスはどれか |
| 弱点 | このリストを社長に見せたら、最初に「これが入っていない」と言われそうなのは何か |
