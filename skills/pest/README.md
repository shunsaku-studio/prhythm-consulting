# pest

## 概要

論点ツリーの問い（Q-xxx）、対象市場、期間を渡すと、その市場の前提を動かすマクロの変化を並べた要因の表と、影響 × 不確かさの振り分けを返す。表の列は、要因 / 事実（[ID] 付き）/ 対象市場への影響の向きと経路 / 時期 / 確からしさ / 影響の大きさ。影響が大きく確かな変化は market-sizing と gap-bridge の成り行きの前提へ、影響が大きく不確かな変化は scenario-sensitivity のシナリオの軸へ渡す。どの要因を持ち越すかは人が決める。出力は `frameworks/pest.md`。

## このフレームワークについて

起源は、Francis Aguilar の『Scanning the Business Environment』（1967 年）である。経営者が社外の情報をどう集めるかを調べた研究の中で、経済・技術・政治・社会の 4 区分（ETPS）を使った。PEST という呼び名は後の人が並べ替えたもので、法律と環境を足した PESTEL（PESTLE）などの変種がある。

何のためか: 自社では動かせない外部の変化のうち、対象市場の需要・価格・コストを動かすものを見落とさないためのチェックリストである。答える問いは「対象市場の前提を変えるマクロの変化は何か。どれが確かで、どれが不確かか」。

何のためではないか: 6 区分を埋める型ではない。業界の儲けの構造（five-forces）、顧客と競合（three-c）、強みと脅威のまとめ（swot）も扱わない。単独の成果物にもしない。表は次のスキルに渡って初めて意味を持つ。

## 利用メリット

- 問い・市場・期間から始めるので、区分を埋めるだけのリストにならない。
- 事実（ID 付き）と解釈（経路）が列で分かれ、どこまでが資料かが見える。
- 確からしさを理由付きで、影響の大きさを自社の露出（構成比など）付きで置く。
- 確かな変化は成り行きへ、不確かな変化はシナリオへ、と渡し先まで決まる。

## 利用シーン

- 成り行きの市場成長を、工業会の見通しのまま置いてよいか確かめたいとき（お題A の 4 段目）
- 新しい市場の需要を、何が生み、何が止めるかを洗い出したいとき（お題C の 2 段目）
- シナリオの軸を、根拠のある変化から選びたいとき（scenario-sensitivity の前）

依頼の例: 「PEST やって」「PESTEL で整理して」「マクロ環境整理して」「外部環境の変化を洗い出して」「市場の前提が変わりそうな要因ある？」

## 使い方

[issue-tree](../issue-tree/README.md) で問いが決まった後に使う。お題A では [market-sizing](../market-sizing/README.md) の前か並行。結果は [market-sizing](../market-sizing/README.md)、[gap-bridge](../gap-bridge/README.md)、[scenario-sensitivity](../scenario-sensitivity/README.md)、[option-longlist](../option-longlist/README.md)、[issue-tree](../issue-tree/README.md) に渡す。

1. 答える論点、対象市場の定義、期間を表の上に書く。問いがなければ始めない。
2. P・E・S・T（必要なら L・E）をチェックリストとして使い、市場を動かす変化の候補を挙げる。該当する変化のない区分は「なし」と理由を書く。
3. 要因ごとに事実を探す。数字は台帳の ID を付ける。台帳にない数字は `skills/number-audit/scripts/add_fact.py` で足す。資料がなければ —。
4. 経路の列に、変化が何を通じて市場に影響するか（+/−/±）を書く。ここだけが解釈である。
5. 時期、確からしさ（高/中/低と理由）、影響の大きさ（自社の露出と ID）を置く。
6. 影響 × 不確かさの表に置き、渡し先を決める。シナリオの軸は 2〜3 個まで。
7. 止まって、持ち越す要因を人に決めてもらう。

## 人が決めること

- 成り行きの前提に入れる要因、シナリオの軸にする要因、見送る要因
- 意見の割れた確からしさ・影響の大きさ
- 何も市場を動かさないなら、分析を打ち切るか

単独度は ○（結果をレビューに出す前提）。決定は `decisions.md` に D-xxx で残す。

## よく外す点

- 問いなしで始め、6 区分を埋める
- 事実の列に「拡大が見込まれる」などの見立てを書く
- 出典のない数字で埋める
- 確からしさを確率で書く、または理由を書かない
- 振り分けをせず、表で終わる
- 循環する市場の平均の伸びを、成り行きに一点で置く

詳しくは [references/pitfalls.md](references/pitfalls.md)。作法の出どころは [references/sources.md](references/sources.md)。

## 具体例

B2B の精密部品メーカー（売上 2,000 億円、自動車・産業機械・電子の 3 事業、海外売上比率 4 割）で、「成り行きの市場成長を業界見通しのまま置いてよいか」に答えた表の抜粋。数字と ID は説明用である。

| 要因 | 事実（[ID] 付き） | 対象市場への影響の向きと経路 | 確からしさ | 影響の大きさ |
|---|---|---|---|---|
| T: EV 化 | 内燃機関向け −2% [F-398]、EV 熱マネジメント向け 15% [F-399]（年平均） | ±。自動車向けの伸びは製品構成で決まる | 中。前の中計で立ち上がりが 1 年遅れた | 大。自動車が売上の 52.5% [F-292] |
| E: 半導体の循環 | 半導体製造装置向け 9% [F-400] | ±。設備投資の上下で受注が先に動く | 低。循環する | 中〜大。産業機械が売上の 30.0% [F-286] |
| E: 見通しの癖 | 過去 3 回 [F-402] の改定ですべて下方修正 | −。見通しは高めに出る | 高 | 大。3 事業すべての成り行きに影響する |
| P: 炭素規制 | —（資料なし） | ±。EV 化を速める。工場のコストを上げる | — | — |

| | 不確かさ 低 | 不確かさ 高 |
|---|---|---|
| **影響 大** | 見通しの癖 → market-sizing の低ケース | EV 化の速さ、半導体の循環 → scenario-sensitivity の軸 |
| **影響 小・中** | — | 炭素規制 → 資料を集めてから置き直す |

S（社会）は「なし」とし、理由を一言書いた。
