# 評価シナリオ（pest）

スキルの出来を確かめるためのお題。採点は [eval-rubric.md](eval-rubric.md) で行う。

## シナリオ1（主）: お題A 売上成長 — 精密部品メーカーの成り行きの前提

### 渡すもの

- 対象: B2B の精密部品メーカー（売上 2,000 億円、自動車・産業機械・電子の 3 事業、海外売上比率 4 割）
- 論点ツリー（どこにいくら足りないか。成り行きの市場成長を業界見通しのまま置いてよいか）
- 業界団体の市場見通し（年平均、FY2025→FY2030）: 自動車向け 3.5%。うち内燃機関向け −2%、EV 熱マネジメント向け +15%。産業機械向け 5%。うち半導体製造装置向け +9%。センサー 8.5%。見通しは過去 3 回の改定ですべて下方修正。為替前提 1 ドル 145 円
- 前の中計の振り返り（EV 化の遅れで熱マネジメント部品の立ち上がりが 1 年後ろ倒し）
- 社長の公の発言（電動化と半導体の微細化が次の 10 年を決める）
- 上の数字を載せたファクト台帳
- 炭素規制の資料はない
- 依頼: 「PEST やって。成り行きの市場成長、業界見通しの数字のままでいいか見たい」

### 期待する振る舞い

| 点検 | 期待 |
|---|---|
| 問い | 表の上に論点、対象市場（業界団体の定義の 3 市場）、期間 FY2025→FY2030 を書く |
| EV 化 | 内燃機関向け −2% と EV 熱マネジメント向け +15% を ID 付きで事実の列に置く。経路に「自動車向けの伸びは製品構成で決まる」と書く。立ち上がりの後ろ倒しを確からしさの理由に使う |
| 半導体の循環 | 半導体製造装置向け +9% を ID 付きで置き、循環することを理由に不確かさ 高に置く。scenario-sensitivity に渡す |
| 為替 | 業界見通しの為替前提 1 ドル 145 円と海外売上比率 41% を ID 付きで置く。円建ての市場規模と売上の両方に効く経路を書く |
| 炭素規制 | 資料にないので事実は —。経路は言葉で書き、前提と未確認事項に回す。数字を作らない |
| 見通しの改定履歴 | 過去 3 回の下方修正を、確からしさを下げる理由として書き、market-sizing の低ケースに渡す |
| 空の区分 | S を埋めない。「なし」と理由を書く |
| 振り分け | 影響 × 不確かさの表で、成り行きの前提とシナリオの軸を分ける。軸は 2〜3 個まで |
| 止まる場所 | 持ち越す要因の判断を人に返す。decisions.md の書き方を示す |
| 台帳 | すべての数字に既存の ID。number-audit でエラー 0 件 |

## シナリオ2（変化球）: お題C 新規参入 — 工場向けエネルギー管理サービス

### 渡すもの

- 対象: 既存事業が成熟し、工場向けエネルギー管理サービスへの参入を考える産業機器メーカー
- 論点ツリー（Q: 工場向けエネルギー管理サービスの需要は、FY2026→FY2032 にどれだけ立ち上がるか）
- 資料: 産業用電力料金の推移、工場の省エネ・脱炭素を求める規制の公表（施行日つき）、導入補助金の公募（年度ごとの予算、継続は未定）
- 案件フォルダはまだない。台帳も空
- 依頼: 「外部環境の変化を洗い出して。出るかどうかの判断材料にしたい」

### 期待する振る舞い

- 先に問いと市場の定義（顧客は国内の工場か、どの規模か、ハードかサービスか）を聞く。決まらないまま始めない
- 資料の数字は add_fact.py で台帳に足してから ID を付ける。台帳を手で書かない
- エネルギー価格は、需要を生む方向（電力料金が高いほど省エネの投資回収が早い）と、不確かさの高さ（価格は上下する）の両方を書く。シナリオの軸の候補にする
- 施行日の決まった規制は不確かさ 低に置き、需要の前提（market-sizing）に渡す。施行日がなければ — と書き、不確かさを上げる
- 補助金は「継続が未定」を理由に不確かさ 高に置く。補助金がなくなった場合の需要を、initiative-sizing の立ち上がりの議論に渡す
- 参入するかどうかを書かない。それは option-evaluation とマネージャーが決める

## シナリオ3（変化球）: 問いのない依頼

### 渡すもの

- 依頼: 「とりあえずこの会社の PEST、全部埋めといて」

### 期待する振る舞い

- 埋める前に、どの問い・どの市場・どの期間の PEST かを聞く。論点ツリーがあればそこから候補を示す
- 6 区分をすべて埋めない。効かない区分は「なし」と書く
- 「示唆」の欄を足さない
