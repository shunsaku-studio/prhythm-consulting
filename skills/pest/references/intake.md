# 何を聞いてから始めるか（pest）

分かっていることは聞かない。分からない値は — のまま進め、「前提と未確認事項」に書く。

## 1. どの問いに答えるか

最初に、論点ツリーのどの問いに答えるための PEST かを確かめる。問いがないなら始めない。

| 問いの例 | 主に見る要因 |
|---|---|
| 成り行きの市場成長は、工業会の見通しどおりでよいか（お題A） | 見通しの前提を崩しうる変化。技術の世代交代、景気循環、為替 |
| 新しい市場の需要は、何が動かすか（お題C） | 需要を生む・止める変化。エネルギー価格、規制、補助金 |
| 中計の外の市場に出るべきか（お題A レーン2、お題D） | 市場が開く・閉じる変化。規制の導入、代替技術 |

`01-issue-tree.md` の Q-xxx か、`00-target-spec.md` の目標を表の上に書く。

## 2. どの市場か

- 製品 × 地域 × 顧客で 1 行で書く（例: 世界の自動車向け精密部品、工業会の定義）
- 統計の定義と、自社の売上定義のずれを書く。ずれは market-sizing で扱うが、ここでも見えるようにする
- 複数の市場を見るときは、市場ごとに要因の表を分けるか、表の中で市場を明記する。「会社全体」の PEST にしない

## 3. いつまでか

- 目標年に合わせる（お題A なら FY2025→FY2030、レーン2 は FY2033 まで）
- 期間の外で影響が出る変化（例: 2035 年の規制）は、期間内に前倒しで影響する経路があるときだけ残す

## 4. 手元にある資料

- `sources/` の業界統計、中計、経営者の発言、有報
- 台帳 `facts/facts.csv` に既にある ID。新しい数字は `add_fact.py` で足す
- 有料レポートやメディア記事は要約と出典だけにする

## 5. 自社の露出

影響の大きさを形容詞でなく露出で書くために、次の値の ID を探す。

| 露出 | 例 |
|---|---|
| セグメントの売上構成比 | 自動車部品 52.5% |
| 海外売上比率 | 41% |
| 特定の製品の比率 | EV 向けの比率（なければ —） |

## 6. 決めておくこと

- L（法律）と E（環境）を見るか。規制や脱炭素が対象市場に影響するなら見る。影響しないなら P と E で足りる
- 誰にレビューに出すか（単独度 ○）
