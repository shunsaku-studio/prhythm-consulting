# eval-scenarios — 評価の場面

## お題A（主）: 北辰工業、ベースケースのあと

- 入力: `cases/hokushin/` の `model/inputs.csv`、`05-initiatives.csv`、`model/model.csv`、台帳。売上目標 T-001（5,000 億円、FY2030 を候補）
- 幅の根拠として使える資料:
  - 工業会の見通し（自動車 3.5%、産業機械 5.0%、センサー 8.5%）と「過去 3 回の改定でいずれも下方修正」（industry-stats.md）
  - 前中計で EV 熱マネジメントの立ち上がりが 1 年後ろ倒し、M&A の上積み 150 億円が未実現（midterm-plan-2025.md）
  - 競合 3 社の営業利益率（competitors.csv。三和プレシジョンは IFRS の事業利益で定義が違う）
  - シェア獲得のベースレート（McKinsey 2017-08）
- 仕込まれやすい問題:
  - 一律 ±10% の幅で回そうとする
  - 競合の利益率の幅に、定義の違う事業利益を混ぜる
  - M&A の不成立を、売上だけ 0 にして投資を残す（または逆）
- 期待する振る舞い:
  - 幅を変数ごとに根拠から決め、出典タグを付け、回す前に人と決める（D-）
  - 立ち上がりの遅れを +1 年 / 0 年の片側で置く
  - M&A を `init_go` で 0 / 1 にする
  - トルネードの上位（M&A、施策の実現率など）を、kpi-roadmap のゲートの候補として書く
  - 下振れが目標に届かないことを、二本目のレーンの根拠として示し、どちらを前に出すかは人に聞く

## 変化形 1: 資本効率（お題B みなと食品）

- 見たい指標は ROE。売上の幅より、利益率と資本の幅が効く。
- 見るところ: 売上のトルネードだけで終わらず、ROIC（と ROE）のトルネードを読むか。利益率の幅を自社の過去から決めるか。

## 変化形 2: 新規参入（お題C 東邦電機）

- 施策 1 本の立ち上がりと単価が答えを決める。根拠になる自社の実績がない。
- 見るところ: 根拠のない幅を `仮置き` と明示し、期限を付けるか。前倒しの上振れを根拠なく置かないか。
