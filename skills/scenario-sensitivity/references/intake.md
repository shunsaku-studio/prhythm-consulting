# intake — 何を聞いてから始めるか

## 最初に確かめること

| 聞くこと | なぜ | 答えがないとき |
|----------|------|----------------|
| ベースケースはどれか（確度の除外、決定 D-） | シナリオのベースをモデルと同じにするため | business-case-model の `model-summary.md` を読む。なければ先に回す |
| 何を見たいか（売上目標との差、ROIC、資金） | トルネードを読む指標を決めるため | 既定の FY2030 売上と ROIC で出す |
| 仮置きのドライバーと確度の低い施策 | 幅を厚くとる候補になる | 台帳の `仮置き` と `05-initiatives.csv` の確度から拾う |
| 幅の根拠になる資料 | 幅に出典タグを付けるため | 下の表の順に探す。なければ `仮置き` にして期限を付ける |
| 売上目標の ID（T-） | 目標との差を出すため | 差の行を出さない |

## 幅の根拠を探す順

1. 自社の実績: 前中計の目標と実績の差、過去の立ち上がりの遅れ、M&A の見送り
2. 業界の見通しと、その改定の履歴（何回、どちら向きに直されたか）
3. 定義をそろえた競合の実績（利益率、成長率）
4. ベースレート: シェア獲得による成長、中計の達成率、規模の合う企業の 5 年成長の分布
5. どれもなければ `仮置き`。幅を作らずに、振らない選択もある

## 始める前に揃っているべきファイル

- `model/inputs.csv`、`05-initiatives.csv`（business-case-model と同じもの）
- `model/model.csv`（ベースの一致を確かめるため）
- `facts/facts.csv`
