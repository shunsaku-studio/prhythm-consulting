# questions — 先輩が聞くとよい問い

先輩質問タイムで使う問いの種。スキルの手順からは呼ばない。

| 観点 | 問い | 聞きたいこと |
|------|------|-------------|
| 結論 | 下振れのとき、FY2030 の売上は目標にいくら届かない？ その大半はどの変数のせい？ | トルネードの上位で結論を言えるか |
| 出所 | 市場成長の下振れの値は、どの資料のどの数字から決めた？ | 幅の根拠を ID と資料のページでたどれるか |
| 前提 | 下振れのシナリオに入れなかった変数はどれ？ なぜ入れなかった？ | 同時に動かす変数の選び方を説明できるか |
| 別解 | 一律 ±10% で振っていたら、トルネードの順番はどう変わっていた？ | 幅を変数ごとに決めた意味を理解しているか |
| 弱点 | このモデルで振れないリスクは何？ | セグメント別の成長、のれん、資金調達など、モデルの外のリスクを自覚しているか |
