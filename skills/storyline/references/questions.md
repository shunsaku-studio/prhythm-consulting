# questions — 先輩が聞くとよい問い

先輩質問タイム③（最終メッセージを確定する前）で使う問いの種。スキルの手順からは呼ばない。

| 観点 | 問い | 聞きたいこと |
|------|------|-------------|
| 結論 | 統治メッセージを、ID を見ずに 30 秒で言ってみて。そのあと、一番強く支えている ID を 1 つ挙げて。 | 自分の言葉で答えを言えるか。答えと根拠をつなげられるか |
| 出所 | 2 ページ目の見出しの数字は、一次資料のどこから来ている？ 推定なら、入力は何？ | ID から資料のページ、計算式までたどれるか |
| 前提 | どの前提が変わると、前に出すレーンが入れ替わる？ | レーンの選択を、特定の仮置きや推定に結びつけて説明できるか |
| 別解 | 後ろに置いたレーンを前に出すと、経営者は何と言いそう？ | 選ばなかったレーンの強さを理解しているか |
| 弱点 | このデッキで、経営者に一番突っ込まれそうなページはどれ？ 何と答える？ | 一番弱い根拠を自覚しているか |
