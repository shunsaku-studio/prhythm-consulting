# 評価シナリオ（swot）

スキルの出来を確かめるためのお題。採点は [eval-rubric.md](eval-rubric.md) で行う。

## シナリオ1（主）: お題A 売上 2.5 倍を目指す精密部品メーカー

### 渡すもの

- B2B の精密部品メーカー（売上 2,000 億円、自動車・産業機械・電子の 3 事業、日本基準）の案件フォルダ一式: 00-target-spec.md（連結売上 5,000 億円、M&A 込み、FY2030。レーン2 は FY2033）、03-gap-bridge.md、facts/competitor-benchmark.md、facts/financial-analysis.md、facts/midterm-plan.md、facts/leadership.md、facts/market-sizing.md、facts/facts.csv
- 比べる相手は 3 社: 自動車部品が主力でオーガニックで伸びた同業 A 社、電子部品が主力で IFRS の B 社、海外同業の買収で売上 5,000 億円規模に届いた C 社
- 依頼: 「SWOT やって。クロス SWOT まで」

### 期待する振る舞い

| 点検 | 期待 |
|---|---|
| 枠 | 先頭に目的（T-xxx）、期限（FY2030、FY2033 は別のレーン）、比べる 3 社と理由、時間軸を書く |
| 相対の S・W | 海外売上比率（自社 41%、3 社は 58〜64%）を、3 社それぞれの値と ID と並べて弱みに置く。売上の年率（自社が 4 社で最も低い）も同じく弱みに置く |
| 定義の違い | 営業利益率の比較で、B 社の事業利益（IFRS）に competitor-benchmark の ※ を引き継ぎ、差の計算に使わない |
| 自己評価 | 社長の「強みは量産立ち上げの速さと技術営業」（本人発言）を S に置かず、未確認の表に置き、確かめ方を書く |
| 目的しだいの項目 | ネット D/E が低く上限まで余地があることを、買収の資金の支えとして書く。競合のネット D/E がなければ、相対の強みとは言わず、その旨を書く |
| O・T | 業界団体の見通し（EV 熱マネジメント向け、半導体製造装置向け、センサーの伸び）を O、内燃機関向けの縮小と見通しの下方修正の履歴を T に置く。会社の行動を O に書かない |
| 上限 | 各象限 5 件以内。証拠で言える強みが 1〜2 件しかなければ、そのまま少なく書く（一般論で埋めない） |
| TOWS | SO・WO・ST・WT の候補に、組み合わせた項目と G-xxx を書く。金額と順位を付けない。04-options.md に同じ打ち手があれば O-xxx を書く。WT（内燃機関向けの縮小など）は守りの手と書く |
| 止まる場所 | 表に残す項目と順位、option-longlist に回す候補を人に聞く（D-xxx） |
| 台帳 | すべての数字に既存の ID。number-audit でエラーを増やさない |

## シナリオ2（変化球）: お題B 資本効率、ROE 5% → 8%

### 渡すもの

- 現預金と政策保有株が厚い食品メーカー（売上 3,000 億円、ROE 5%、PBR 1 倍割れ、日本基準、ネット・キャッシュ）の financial-analysis と competitor-benchmark の出力
- 依頼: 「強み弱み整理して。財務が健全なのは強みだよね？」

### 期待する振る舞い

- 目的（ROE 8%）を先頭に書き、その目的に照らして項目を置く
- 厚い手元資金と高い自己資本比率を、自動的に強みにしない。ROE の目的では、資本の使い方の弱み（財務レバレッジが同業より低い、など）になりうると書く。同業の値と ID で示す
- 一方で「資金の余力」は、成長投資や株主還元の選択肢を広げる材料として TOWS に使えると書く（SO か WO）
- 依頼者の「強みだよね？」に合わせず、目的によって評価が変わることを示し、判断を人に返す
- 政策保有株の時価や売却の方針は、データがなければ未確認に置く

## シナリオ3（変化球）: 比べる相手がいない

### 渡すもの

- 財務データだけ（facts/financials.csv と financial-analysis）。competitor-benchmark の出力はない
- 依頼: 「とりあえず SWOT 作って」

### 期待する振る舞い

- 目的を聞く。目的が決まるまで項目を書かない
- 比べる相手がないので、S と W はすべて未確認の表に置き、competitor-benchmark を先に回すよう勧める
- 自社の過去との比較（営業利益率の推移など）は、競合との差ではないと明記したうえで参考に書く
- 一般的な言葉で表を埋めない
