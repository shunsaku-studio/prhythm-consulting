# 手順と、なぜその順か（swot）

SWOT はよく使われるが、使い方を誤ると何も決まらない表になる。Hill & Westbrook（1997）は、20 社あまりの SWOT を調べ、5 つの欠点を挙げた。この手順は、その 5 つに一つずつ対処するように組んである。出典は [sources.md](sources.md)。

| 欠点（Hill & Westbrook） | この手順での手当て |
|---|---|
| 項目が多すぎる（平均 40 超） | 象限ごとに 5 件まで（目安 3 件）。順位は人が決める |
| 一般的で意味のない言葉 | S・W は名前を挙げた競合との差で書く。O・T は外部の事実で書く |
| 優先順位がない | 目的との関係の列を必須にし、人が順位を決める |
| 裏付けがない | すべての項目に台帳の ID。ないものは未確認の表へ |
| 後の工程で使われない | TOWS で打ち手の種にし、option-longlist に渡す |

## 1. 枠を決める（目的・相手・時間軸）

目的、比べる相手、時間軸をファイルの先頭に書く。項目はそのあとに書く。

なぜ: Koch（2000）は、SWOT は戦略ごと・目的ごとに作るものだと述べた。同じ事実でも目的で意味が変わる。手元資金が多いことは、買収で売上を伸ばす目的には支えになるが、ROE を上げる目的には重しになる。

## 2. 外部から書く（O・T）

市場と環境で、期限までに何が変わるかを書く。会社が動かせないものだけを置く。

なぜ: Weihrich（1982）は TOWS を外部環境の分析から始め、しかも今だけでなく将来の時点で見ることを勧めた。外部を先に置くと、内部の項目を「その変化に対して役に立つか」で選べる。

- 良い: 「EV 熱マネジメント向けの世界市場は年 15% [F-xxx] の見通し」
- 悪い: 「EV 市場に参入できる」（これは会社が取る行動で、機会ではない。TOWS の欄に書く）

## 3. 内部を相対で書く（S・W）

強みと弱みは、名前を挙げた競合と比べて書く。両方の値に ID を付ける。

なぜ: 絶対値で良くても、競合も同じなら差にならない。強みとは、目的に対して競合より有利なものだけである。

各強みに、VRIO（Barney 1995）の四つの問いを一行で当てる。

| 問い | 中身 |
|---|---|
| 価値（Value） | この目的に役立つか |
| 希少性（Rarity） | 比べた競合の多くが持っていないか |
| 模倣困難性（Inimitability） | 競合がすぐに真似できないか |
| 組織（Organization） | 会社はそれを使う仕組みを持っているか |

公開情報で答えられない問いは — とする。Valentin（2001）は、SWOT が資源の価値を問わないまま強みを並べがちだと指摘した。VRIO の行はその手当てである。

## 4. 裏付けのないものを分ける

経営者の自己評価（「強みは量産立ち上げの速さ」）、メディアの解釈、競合と比べていない項目は、未確認の表に入れる。確かめる方法（どの資料のどの数字か）を書く。

なぜ: 自己評価は手がかりであって、証拠ではない。表に混ぜると、本物の強みと見分けがつかなくなる。

## 5. 絞って順位の案を出す

象限ごとに 5 件まで。目的との関係が強い順に並べた案を出すが、順位は人が決める。

## 6. TOWS（クロス SWOT）で打ち手の種にする

| | O（機会） | T（脅威） |
|---|---|---|
| **S（強み）** | SO: 強みで機会を取る | ST: 強みで脅威をかわす |
| **W（弱み）** | WO: 機会を使って弱みを補う | WT: 弱みと脅威が重なる所の守り |

- 各候補に、組み合わせた項目（`S1×O2`）と、対応するギャップ（G-xxx）を書く
- WT は守りの手であり、成長の柱にはならないと書き添える
- ここでは見積もらない、順位を付けない、O- の ID を振らない。O-xxx は option-longlist が振る
- 既に `04-options.md` に同じ打ち手があれば、その O-xxx を括弧なしで書く

なぜ: TOWS は Weihrich が SWOT を戦略の候補に変えるために作った。SWOT を打ち手のロングリストにつなげると、「後で誰も使わない」欠点を防げる。

## 7. 人に返す

レビュー（○）に出し、次の二つを決めてもらう。

1. 表に残す項目と順位
2. option-longlist に回す TOWS の候補（回す / 保留 / 落とす）

決定は `decisions.md` に D-xxx で残す。決まる前に option-longlist へ渡さない。
