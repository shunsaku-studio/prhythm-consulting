# three-c

## 概要

一つの市場と一つの問い（どのセグメントなら勝てるか、参入して勝てるか）を渡すと、顧客・競合・自社を同じ「購買基準」の行で並べた 3C の表を返す。順番は、顧客（誰が何のために買うか、何で選ぶか、規模と成長）→ 競合（同じ基準をどう満たしているか）→ 自社（同じ基準をどう満たしているか）→ セグメントごとの KSF（成功のカギ）と適合・ギャップ。事実（台帳の ID 付き）と解釈・仮説は別の列に分け、分からないところは — で残す。どのセグメントと KSF を次に持っていくかは人が決める。

## このフレームワークについて

3C は大前研一が『企業参謀』（1975 年）と英語版の The Mind of the Strategist（1982 年）で示した「戦略的三角関係」である。顧客（Customer）・競合（Competitor）・自社（Company）の三つを一体で見て、顧客が選ぶ理由のうえで、競合より自社が上回れる場所を探す。強みとニーズが合うだけでは足りない。同じニーズを競合がもっとうまく満たしていれば勝てない。

答える問いは「どの顧客に対して、何で、競合より勝てるか」である。会社の紹介でも、知っていることの一覧でもない。SWOT の代わりでもない。マクロ環境は pest、業界の構造は five-forces が扱う。協力者（Collaborators）や環境（Context）を足した 4C・5C もあるが、起源ははっきりしない。必要な問いのときだけ足す。出典は [references/sources.md](references/sources.md)。

## 利用メリット

- 「3C やって」と言われて、三つの箇条書きで終わらずに済む。問いとセグメントを先に決めるからだ。
- 三つの C を同じ購買基準の行でそろえるので、KSF が表から読める。「強みがある」と「競合より上」を取り違えない。
- 事実と仮説が列で分かれる。アウトサイドインでは顧客の基準がまだ仮説であることが、誰にでも見える。
- 仮説ごとに確かめる方法（誰に何を聞くか）が付くので、受注後のインタビューの計画にそのまま使える。

## 利用シーン

- お題A（売上成長）で、伸びる市場のどこに重心を移すかを見たいとき。market-sizing と competitor-benchmark の後、option-longlist の前
- お題C（新規参入）で、出て勝てるか、勝てるならどの顧客層かを整理したいとき。顧客の側はほぼ仮説になる
- 「この業界の KSF は何か」「うちの強みは顧客に効いているか」と問われたとき

依頼の例: 「3C やって」「顧客・競合・自社で整理して」「KSF 何？」「どのセグメントなら勝てる？」「この市場、参入して勝てる？」

## 使い方

**いつ使うか:** [market-sizing](../market-sizing/README.md) で市場の規模と成長が、[competitor-benchmark](../competitor-benchmark/README.md) で競合の数字がそろった後に入る。問いは [issue-tree](../issue-tree/README.md) の Q-xxx から取る。結果は [option-longlist](../option-longlist/README.md) に渡す。

1. 問い、市場、セグメント（顧客の使い方で 2〜4 個）を決める。問いがなければスキルは聞き返す。
2. 顧客: セグメントごとに規模と成長を台帳の ID で書き、購買基準を 3〜6 個置く。アウトサイドインでは基準と重みはすべて仮説で、確かめる方法を添える。
3. 競合: 同じ基準の行で、各社がどう満たしているかを書く。代替品（顧客の内製など）と新規参入者も検討する。読めないところは —。
4. 自社: 同じ基準の行で書く。強みは [leadership-lens](../leadership-lens/README.md) の本人発言から、短い一句と出典で。数字は [financial-analysis](../financial-analysis/README.md) などの ID を使う。
5. セグメントごとに KSF を 1〜2 個選び、一番強い競合に対する位置（上回る / 並ぶ / 下回る / —）とギャップを書く。点数で順位を付けない。
6. `frameworks/three-c.md` に書いて止まり、人の判断を待つ。

台帳にない数字が要るときは `skills/number-audit/scripts/add_fact.py` で足す。CSV を手で編集しない。

## 人が決めること

- 次の段に持っていくセグメントと KSF（decisions.md に D-xxx で残す）
- 仮説のまま進むか、インタビューを先にするか
- 協力者や環境（4C・5C）の行を足すか

単独度は ○（結果をレビューに出す前提）。スキルはセグメントを選ばず、示唆や推奨も書かない。

## よく外す点

- 問いを決めずに始め、三つの箇条書きで終わる
- 自社の強みから書き始め、それを顧客の基準だと思い込む（プロダクトアウト）
- 三つの C を別々の軸で書き、KSF が導けない
- 顧客の基準を、インタビューなしに事実として書く
- 「強みがある」で勝てると考え、競合と比べない
- 競合を同業だけにし、顧客の内製や別の技術を見落とす

詳しくは [references/pitfalls.md](references/pitfalls.md)。SWOT に渡すときは [swot](../swot/README.md) の強み・弱みの材料になるが、この表を正本にする。

## 具体例

B2B の精密部品メーカー（売上 2,000 億円、自動車・産業機械・電子の 3 事業）が、伸びる 3 市場のどこで勝てるかを公開情報だけで見たときの抜粋（説明用。数字と ID は例示）。KSF はどれも仮説である。

| セグメント | KSF（仮説） | 自社の位置 | ギャップ |
|---|---|---|---|
| EV 熱マネジメント（年 15% [F-xxx]） | 量産立ち上げの速さ、設計段階からの共同開発 | 国内は並ぶか上回る（仮説）。国内シェア約 12% [F-xxx]、海外は — | 海外への供給。海外売上比率は同業 3 社より低い |
| 半導体製造装置向け（年 9% [F-xxx]） | 精度と清浄度、能力の確保 | — | 判断の材料がない（顧客の基準も競合の位置も公開情報にない） |
| 産業用センサー（年 8.5% [F-xxx]） | 海外の販路 | 下回る（仮説）。電子部品が主力の同業は海外売上比率が高い | 海外の販路。自前か提携か |

読み方: 上回る根拠があるのは EV 熱マネジメントの国内だけで、それも顧客の声では確かめていない。半導体製造装置向けは「勝てる」とも「勝てない」とも言える段にない。どれを次に持っていくかは人が決める。
