# 評価シナリオ（three-c）

スキルの出来を確かめるためのお題。採点は [eval-rubric.md](eval-rubric.md) で行う。会社は業種と事業の形だけで示す。数字は説明用で、評価のときは手元の台帳の ID で置き換える。

## シナリオ1（主）: お題A 精密部品メーカーの成長市場

### 渡すもの

- B2B の精密部品メーカー（売上 2,000 億円、自動車・産業機械・電子の 3 事業、日本基準）。売上目標を大きく引き上げたい
- `facts/market-sizing.md`: 業界団体の見通しによる 3 市場の規模と成長。自動車向けのうち EV 熱マネジメント向けは年 15%、内燃機関向けは年 −2%。産業機械向けのうち半導体製造装置向けは年 9%。産業用センサーは年 8.5%。自社の定義に合う対象市場は、仮置きの割合に乗っている
- `facts/competitor-benchmark.md`: 同業 3 社（自動車部品が主力の同業、電子部品が主力で IFRS の同業、買収で伸びた同業）。事業構成、海外売上比率、M&A 投資額はあるが、製品ごとの強さはない
- `facts/leadership.md`: 社長の本人発言（強みは量産立ち上げの速さと、設計段階から入る技術営業。自動車部品の比率を下げたい）
- `facts/midterm-plan.md`: 前中計で EV 熱マネジメント部品の立ち上がりが 1 年遅れた
- 統合報告書: EV 熱マネジメント部品の国内シェア約 12%。世界シェアは非開示
- 依頼: 「3C やって。EV 熱マネジメント、半導体製造装置向け、産業用センサーのどこで勝てるか見たい」

### 期待する振る舞い

| 点検 | 期待 |
|---|---|
| 問いとセグメント | 問い（どのセグメントで勝てるか、論点ツリーの「何で埋めるか」の下）と 3 セグメントを冒頭に書く |
| 順番 | 顧客 → 競合 → 自社 → KSF の順。三つの表が同じ購買基準の行を持つ |
| 顧客の事実 | 市場の成長を台帳の ID で書く。対象市場が仮置きの割合に乗っていること、業界の見通しが下方修正を繰り返してきたことを書く |
| 顧客の仮説 | 購買基準と重みはすべて 仮説。確かめるインタビュー（誰に、何を）を添える |
| 競合 | competitor-benchmark の ID を使う。製品ごとの強さは公開情報から読めないので — か 仮説。IFRS の同業の利益率を日本基準と並べない。代替品（顧客の内製など）を検討する |
| 自社 | 国内シェアは国内の値で、世界シェアは — と書く。強みは本人発言の短い一句と出典。立ち上がりが前中計で遅れた事実を、強みの発言と並べて書く |
| 制約 | EV 熱マネジメントで伸びるほど自動車部品の比率が上がり、社長の発言とぶつかることを書く |
| KSF と適合 | セグメントごとに KSF を 1〜2 個、購買基準の行から選ぶ。一番強い競合に対する位置を 上回る / 並ぶ / 下回る / — で書く。材料のないセグメントは — のまま。点数で順位を付けない |
| 止まる場所 | どのセグメントと KSF を持っていくかを人に聞く。D-xxx で残す形を示す |
| 台帳 | 新しい数字を作らない。要るときは add_fact.py で足す。number-audit でエラーが増えない |

## シナリオ2（変化球）: お題C 産業機器メーカーの新規参入

### 渡すもの

- 既存事業が成熟した産業機器メーカー。工場向けエネルギー管理サービスに出るか検討中
- 市場規模の公開資料が 1 つ（定義があいまい）。競合はシステム会社 2 社と電力会社系 1 社。顧客インタビューはまだない
- 依頼: 「参入して勝てるか、3C で整理して」

### 期待する振る舞い

- 問いを「参入して勝てるか。勝てるならどの顧客層か」と書く
- 顧客を使い方で分ける（例: 電力の使用量を減らしたい大工場 / 脱炭素の開示が要る上場企業の工場 / 設備の保全と一緒に見たい中堅工場）。分け方そのものも仮説と書く
- 顧客の購買基準と重みはすべて 仮説。インタビューの計画（対象、問い、何が分かれば仮説が崩れるか）を前提と未確認事項に並べる
- 市場の定義があいまいなことを書き、market-sizing に渡す。規模を一つの推定で埋めない
- 競合に電力会社系や、顧客の内製（自前の設備管理部門）を入れる
- 自社の強み（既存の工場顧客との関係など）が、どの購買基準の行で役に立つかを書く。どの行でも役に立たない強みは強みとして扱わない
- 結論を出さず、「仮説のまま進むか、インタビューを先にするか」も人に返す

## シナリオ3（変化球）: 問いのない依頼

### 渡すもの

- シナリオ1 と同じ材料
- 依頼: 「この会社の 3C やっといて」

### 期待する振る舞い

- 始める前に、何を決めるための 3C かを聞き返す（どのセグメントで勝てるか、など）
- 会社全体の 3C を書き始めない。三つの箇条書きを返さない
- 問いが返ってきたら、セグメントの切り方を確かめてから始める
