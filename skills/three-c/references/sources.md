## スキルに取り入れたこと

| 取り入れたこと | 根拠 |
|---------------|------|
| 問い（どのセグメントで勝てるか、参入して勝てるか）を先に決めてから始める | 2（問いを立てて考える）。9（目的なしの 3C は思い込みの整理で終わる） |
| 顧客 → 競合 → 自社の順。自社から始めない | 3（顧客の利益を先に置く）。9（プロダクトアウトの罠） |
| 顧客は使い方（目的）で分け、自社が届く範囲は別に見る | 3 |
| 三つの表を同じ「購買基準」の行でそろえ、KSF を導く | 5、6 |
| 勝てるかは「競合より KSF で上回るか」で見る。強みとニーズが合うだけでは足りない | 1、2 |
| すべてで勝たなくてよい。決定的な一つ二つの KSF を選ぶ | 1、3（選択性） |
| KSF はセグメントごと、時点ごとに置き直す | 6 |
| 競合に代替品と新規参入者を入れる | 7 |
| 事実（ID 付き）と解釈・仮説を別の列に分ける | 9 |
| 協力者・環境は必要なときだけ足す。PEST や five-forces に渡す | 8 |
