# 評価シナリオ（value-chain）

スキルの出来を確かめるためのお題。採点は [eval-rubric.md](eval-rubric.md) で行う。会社は業界と事業の形だけで示す。

## シナリオ1（主）: お題A B2B の精密部品メーカーの自動車部品事業

### 渡すもの

- B2B の精密部品メーカー（売上 2,000 億円、自動車・産業機械・電子の 3 事業、日本基準）。売上目標の大幅な引き上げを検討している
- 統合報告書のトップメッセージ: 社長が「強みは量産立ち上げの速さと、顧客の設計段階から入り込む技術営業」と述べている（leadership-lens で 本人発言 とラベル済み）
- 前の中計の振り返り: EV 向け熱マネジメント部品の立ち上がりが、EV 化の遅れで 1 年後ろ倒しになった
- 統合報告書: EV 熱マネジメント部品の国内シェアは「約 12%」と記載。世界シェアは非開示
- financial-analysis の出力（設備投資 ÷ 売上、減価償却 ÷ 売上、セグメント利益率。いずれも台帳の ID 付き）。研究開発費は抜粋にない
- competitor-benchmark の出力: 同じ自動車部品で競う国内の同業 2 社（オーガニック中心の 1 社、海外の同業の買収で伸びた 1 社）
- 依頼: 「社長が言ってる強み、本当にあるのかバリューチェーンで見て。どこで稼いでるか分解して」

### 期待する振る舞い

| 点検 | 期待 |
|---|---|
| 範囲 | 事業を自動車部品に絞り、産業機械部品と電子部品は別のチェーンとして描かないと書く。連結で 1 本にしない |
| 活動の言い換え | 一般形の「販売・マーケティング」を「受注前の技術営業・設計参画」に、「製造」を「試作・量産立ち上げ」と「量産」に分ける。言い換えた理由を書く |
| 会社の主張 | 量産立ち上げの速さと設計段階からの技術営業を「会社の主張」とラベルし、出典（統合報告書のページ）を書く。事実として書かない |
| 連結 | 設計参画 → 量産立ち上げの連結を、仮説として矢印で書き、確かめ方（試作から量産までの期間、設計変更の回数）を添える |
| 反証の材料 | 前の中計で熱マネジメント部品の立ち上がりが 1 年遅れたことを、「立ち上げの速さ」と食い違う事実として挙げる（原因が市場側か自社側かは未確認と書く） |
| 強度の根拠 | 設備投資 ÷ 売上、減価償却 ÷ 売上は連結の値として ID 付きで置き、「活動別は不明」と書く。研究開発費、活動別の原価は — |
| 競合 | 同業 2 社との違いは、利益率・海外売上比率など ID のある値と、定性または — で書く。全体の噛み合いを断定しない |
| 価値システム | 顧客（完成車メーカー・一次部品メーカー）の設計工程に入ることを、価値システムの図で示す |
| 止まる場所 | どの活動を優位と見なすか、make / buy / partner の候補にするかを並べて止まる。D-xxx を勝手に書かない |
| 台帳 | すべての数字に台帳の ID。number-audit で新しいエラー 0 件 |

## シナリオ2（変化球）: お題D 事業の整理と買収を同時に考える化学メーカー

### 渡すもの

- 化学メーカー（日本基準。機能材料、基礎化学品、化成品の 3 事業）。オーガニック成長だけでは中計の目標に届かず、買収で補いたい。化成品を経営者が「ノンコア」と呼んでいる
- 買収候補: 機能材料で競う国内の中堅メーカー 1 社（公開情報のみ）
- 依頼: 「買収したらどこが重なるか、バリューチェーンで見て。あわせて、化成品を切り出すと何が残るかも」

### 期待する振る舞い

- チェーンを 2 本に分ける: 機能材料（自社と候補を並べる）と化成品（切り出しの検討）。会社全体で 1 本にしない
- 統合シナジー: 重なる活動（調達、生産拠点、販売チャネル、研究開発）を項目で挙げ、コストシナジーと売上シナジーを分ける。売上シナジーは実現しにくいと書く。金額は出さず business-case-model に渡す
- カーブアウト: 化成品が本体と共有する支援活動（研究所、調達契約、基幹システム、経理・人事、拠点）を棚卸しする。切り出された側のディスシナジーと、本体の残存コストの候補を挙げる
- 一時費用の外部の目安（BCG 2021、売上の約 1〜5%）を使うなら、台帳に公開で登録して ID を付ける。案件の数字の代わりにしない
- 候補の活動は公開情報で多くが — になる。インサイドアウトで取るデータ（拠点別の原価、共有契約の一覧、共有人員）を並べる
- どの重なりをシナジーと見なすか、どの共有活動を切り出しの障害と見なすかは人に返す

## シナリオ3（変化球）: 「9 つの箱を全部埋めて」

### 渡すもの

- シナリオ1 の入力
- 依頼: 「Porter の 9 つの箱を全部埋めた表がほしい。会社全体で」

### 期待する振る舞い

- 会社全体で 1 本にしないことと、その理由（事業でコスト要因と顧客が違う）を短く伝え、どの事業から描くかを聞く
- 一般形の 9 つの箱を出発点として示したうえで、言い換えた活動の表を返す。部品メーカーで中身の薄い箱（例: 一般形の出荷物流）は、まとめた理由を書く
- 外から分からない箱を、もっともらしい文や推定の割合で埋めない。— とインサイドアウトの項目で残す
