# 手順と、なぜその順か（value-chain）

## 1. 範囲を先に決める

事業、問い、比べる競合を決めてから描く（[intake.md](intake.md)）。問いが決まらないと、9 つの箱を全部同じ濃さで埋めることになり、どこにも答えない表になる。

## 2. 活動を業界に合わせて言い換える

Porter の 5 つの主活動と 4 つの支援活動は出発点である。そのまま使わない。

| Porter の一般形 | B2B 部品メーカーでの言い換えの例 | 言い換える理由 |
|---------------|-------------------------------|--------------|
| 販売・マーケティング | 受注前の技術営業・設計参画 | 部品は顧客の設計に採用されて初めて売れる。広告ではなく設計段階での提案が売る活動になる |
| 製造 | 試作・量産立ち上げ / 量産 | 立ち上げと量産ではコスト要因が違う（立ち上げは習熟とタイミング、量産は規模と稼働率） |
| 購買物流・出荷物流 | 調達・入荷 / 品質保証・納入 | 顧客のライン近くへの納入と品質保証が、取引の条件になる |
| サービス | 補給・設計変更対応 | 量産後の補給部品と設計変更への追従 |
| 技術開発 | 材料・工法の開発、生産技術 | 製品開発と、作り方の開発を分ける |
| 調達 | 材料・設備の調達 | 主活動の調達・入荷と、契約の交渉を分ける |

言い換えた理由、まとめた箱、落とした箱を成果物に書く。McKinsey のビジネスシステムも、段の数と名前は業界に合わせて決める（[sources.md](sources.md) #4）。

なぜ先にやるか: 一般形のまま埋めると、「出荷物流: 製品を顧客に届ける」のような、どの会社にも当てはまる文で埋まる。業界の言葉に直すと、その事業で本当に効く活動が見える。

## 3. 会社がやっていることを書く

活動ごとに、会社が何をしているかを公開資料から書く。資料名とページを付ける。分からなければ —。

## 4. 強度の根拠と、要因を書く

### 強度の根拠

活動にどれだけコストや資産がかかっているかの根拠。外から取れるのは、多くが連結かセグメントの数字である。

| 取れることが多い | 取れないことが多い（インサイドアウト） |
|---------------|-------------------------------|
| 設備投資 ÷ 売上、減価償却 ÷ 売上（financial-analysis）| 活動ごとの原価・人員・資産の割り付け |
| 研究開発費 ÷ 売上（有報にあれば） | 立ち上げ期間、良品率、稼働率 |
| セグメント利益率 | 顧客ごとの採用率、試作から量産への転換率 |
| 従業員数（有報） | 調達単価、物流費 |

- 数字は台帳にあるものだけ。ID を付ける
- 連結の数字を活動の行に置くときは「連結。活動別は不明」と書く
- 取れない値は — にして、「インサイドアウトで取るデータ」に並べる

### コスト要因と差別化要因

Porter は活動ごとにコスト要因と差別化要因を挙げた（[sources.md](sources.md) #1）。

| コスト要因の型 | 問い |
|--------------|------|
| 規模 | 量が増えると単価は下がるか |
| 習熟 | やるほど速く・安くなるか |
| 稼働率 | 設備が空くとコストが上がるか |
| 連結 | ほかの活動のやり方で、この活動のコストが変わるか |
| 相互関係 | ほかの事業と共有していて安いか |
| タイミング | 先に入った・後に入ったことが効くか |
| 方針 | 自分で選んだやり方（品揃え、品質水準）で決まるか |
| 立地・制度 | 拠点の場所、規制、脱炭素の要求で変わるか（Porter & Kramer の共有価値の考え方も、ここに入る） |

差別化要因は「顧客が何に払い、何で選ぶか」。部品なら、採用されるまでの速さ、設計への提案、品質、納入の確かさなど。

### ラベル

すべての要因と強みに、次のどれかを付ける。

- **事実**: 資料で確かめた（資料名とページ）
- **会社の主張**: 会社が自分で言っている（誰が、どこで）。裏が取れるまで事実にしない
- **仮説**: こちらの読み。確かめる方法を添える

## 5. 連結と価値システムを描く

優位は箱の中より、箱と箱の間にあることが多い。Porter は「何をやらないか」と、活動どうしの噛み合いが真似しにくさを生むと書いた（[sources.md](sources.md) #6）。

- **チェーンの中の連結**: 例「設計段階で入り込むから、量産の立ち上げが速い」。どちらの活動がどちらを助けるかを矢印で書く
- **価値システム**: 供給業者のチェーン、顧客のチェーン（顧客の設計工程・量産工程のどこに入るか）。部品メーカーは顧客のチェーンのどこに入るかで勝負が決まりやすい

連結も、事実か会社の主張か仮説かを書く。

## 6. 競合と比べる

活動ごとに、競合がどうしているかを書く。公開情報では、多くが定性か — になる。それでよい。

- 比べるのは活動ごとのやり方。数字は competitor-benchmark の ID を使う
- 「個々の活動は比べやすいが、全体の噛み合いは比べにくい」（[sources.md](sources.md) #2）。噛み合いの比較は仮説として書く

## 7. make / buy / partner の候補（問いがそれのとき）

候補を並べるだけで、決めない。

| 見る点 | 外に出す・組む候補になりやすい | 自前で持つ候補になりやすい |
|-------|----------------------------|------------------------|
| 差別化への効き | 顧客が選ぶ理由になっていない | 選ばれる理由になっている |
| 規模 | 規模が自社の外にある（専業のほうが安い） | 自社の規模で十分 |
| 連結 | ほかの活動から切り離せる | 強みの連結の一部である |

## 8. シナジーとカーブアウト（お題D）

### 統合シナジー

- 両社のチェーンを並べ、重なる活動を出す
- コストシナジー（重なる活動をまとめる）と売上シナジー（相手の顧客に売るなど）を分ける。売上シナジーは顧客の行動しだいで、実現しにくい（[sources.md](sources.md) #10）
- 金額は出さない。項目だけ挙げ、business-case-model に渡す

### カーブアウト

- 切り出す事業が本体と共有している支援活動（調達契約、IT、経理・人事、拠点、ブランド、研究所）を棚卸しする
- 切り出すと、切り出された側の規模が小さくなって単価が上がる（ディスシナジー）。本体には、移行サービスの後も消えないコスト（残存コスト）が残る（[sources.md](sources.md) #8）
- 一時費用の外部の目安（売上の約 1〜5%）を使うなら、台帳に `公開` で登録し ID を付ける。案件の数字の代わりにしない

## 9. 人に返す

候補を、ラベルと根拠を付けて並べ、止まる。どれを優位と見なすか、どれを make / buy / partner の候補にするかは人が決める。決まったら decisions.md に D-xxx で残す。

## 10. 渡す

- 優位の活動と、弱い活動 → option-longlist（打ち手の材料、自前・提携・買収の列）
- 設備がどの活動にあるか、切り出しの売却資金 → capital-capacity
- シナジーとディスシナジーの項目 → business-case-model で金額にする
- 同じ会社の three-c や swot の「強み」は、この表の活動を指すようにする
